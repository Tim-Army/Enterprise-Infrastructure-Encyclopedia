# Volume LXXVIII Glossary

Definitions for terms introduced in **Volume LXXVIII — Tenable Certification Tracks**.
See the [master glossary](../../GLOSSARY.md) for cross-volume terms.

- **ACR (Asset Criticality Rating)** — Tenable's measure of how important an asset is to the business, used to weight prioritization.
- **AES (Asset Exposure Score)** — a per-asset score combining its vulnerabilities (VPR) with its criticality (ACR).
- **ARC (Assurance Report Card)** — a Security Center report that measures security posture against defined policies (pass/fail).
- **Attack Path Analysis** — Tenable One analysis that maps how an attacker could chain misconfigurations, vulnerabilities, and identities to reach a critical asset.
- **Attack Surface Management (ASM)** — discovery of internet-facing assets an organization may not know it owns.
- **CES (Cyber Exposure Score)** — Tenable One's organization-wide exposure metric.
- **Credentialed scan** — an authenticated scan that logs in to inspect installed software, patches, and configuration for accurate results.
- **CSPM / CNAPP** — cloud security posture management / cloud-native application protection; detecting cloud misconfigurations and risks.
- **CVSS** — Common Vulnerability Scoring System; a static technical severity score (0–10).
- **DAST** — Dynamic Application Security Testing; testing a running application from the outside (Tenable Web App Scanning).
- **Exposure management** — the practice of managing an organization's real, cross-domain exposure and attack paths, rather than counting siloed vulnerabilities.
- **Nessus** — Tenable's vulnerability scanner, the engine beneath the platform.
- **Nessus Agent** — a host-installed sensor providing always-authenticated, network-independent scanning of laptops and cloud instances.
- **NASL** — Nessus Attack Scripting Language, used to write plugins.
- **Plugin** — a Nessus program that checks for a specific vulnerability, misconfiguration, or information item.
- **Repository** — a Security Center data store for scan results, scoped by network or purpose.
- **Scan zone** — a Security Center construct that routes scans to the appropriate scanner for a network segment.
- **Security Center** — Tenable's on-premises vulnerability-management console (formerly Tenable.sc).
- **Tenable One** — Tenable's exposure-management platform unifying vulnerability, web, cloud, OT, and identity exposure.
- **Tenable OT Security** — Tenable's product for operational-technology visibility and exposure, using passive monitoring.
- **Tenable Vulnerability Management** — Tenable's cloud vulnerability-management platform (formerly Tenable.io).
- **Toxic combination** — a set of individually-minor issues that together form a real attack path (e.g., internet-facing + vulnerable + admin role).
- **VPR (Vulnerability Priority Rating)** — Tenable's dynamic score combining CVSS with threat intelligence to reflect actual exploitation likelihood.
- **WAS (Web Application Scanning)** — Tenable's DAST product for testing running web applications.
