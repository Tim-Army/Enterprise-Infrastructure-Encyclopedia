# Volume LXXVIII — Tenable Certification Tracks

> The whole Tenable certification program in one volume — the Vulnerability Management, Security
> Center, and OT Exposure product certifications across Nessus, Tenable VM, Security Center, Web App
> Scanning, Cloud Security, OT Security, and Tenable One exposure management — with hands-on,
> defensive labs, verified against tenable.com.

## Overview

Volume LXXVIII maps the **Tenable** certification program — the credentials for operating Tenable's
**vulnerability- and exposure-management** platform, from the **Nessus** scanner to the **Tenable
One** exposure-management platform. Tenable currently offers three product certifications: **Tenable
One Vulnerability Management**, **Tenable Security Center**, and **Tenable One OT Exposure**, each a
**two-part written + practical** exam, online proctored, valid **two years**. It joins the
encyclopedia's security volumes (Qualys LXXIX, CyberArk LXXVII, GIAC LXXIV, Gigamon XVIII, Wireshark
XX, Enterprise Cybersecurity X).

This is a **certification-tracks** volume, like the other vendor volumes (XXXIX–LXXVII): it maps the
program — the certifications and products — and teaches each with a hands-on walkthrough. Every
certification and product area was **verified against tenable.com on 28 July 2026**.

Chapters follow the platform:

- **Chapter 01** frames the program — the three certifications, the two-part exam, and the products.
- **Chapter 02** takes **Nessus and scanning fundamentals** (plugins, policies, credentialed scans).
- **Chapters 03–04** take **Tenable Vulnerability Management**: asset discovery/scanning, then analysis and prioritization (CVSS/VPR/AES).
- **Chapter 05** takes **Tenable Security Center** (on-prem console).
- **Chapter 06** takes **Web App Scanning and Cloud Security**.
- **Chapter 07** takes **Tenable OT Security**.
- **Chapter 08** takes **Tenable One** exposure management.
- **Chapter 09** covers certification prep, currency, and career.

Every chapter follows the standard structure defined in
[templates/chapter.md](../../templates/chapter.md) and enforced by
[EDITORIAL_STANDARDS.md](../../EDITORIAL_STANDARDS.md), including per-topic hands-on labs and
knowledge checks.

> **Scope.** Vulnerability and exposure management is a defensive discipline. Every lab is
> **authorized administration** — scanning, prioritizing, and remediating on systems you are
> authorized to assess — never an attack. Scan only assets you own or are authorized to scan.
