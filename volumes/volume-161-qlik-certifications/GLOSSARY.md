# Volume CLXI — Glossary

| Term | Definition |
|:---|:---|
| **Associative Engine** | Qlik's signature in-memory data engine where all data is associated through common fields, enabling instant, free-form exploration in any direction — the foundation of the platform and every certification. |
| **Business Analyst (QSBA)** | The Qlik role and expert certification (50Q/90min/62%, platform-neutral) for designing apps and building visualizations and analysis — choosing the right chart, designing selection-driven exploration, and building stories. |
| **Data Architect (QSDA)** | The Qlik role and expert certification (50Q/90min/62%, platform-neutral) for designing, building, and validating the data model — the Data Load Editor, clean associations, avoiding synthetic keys, and QVD loading. |
| **Data Literacy Qualification** | Qlik's non-technical, product-agnostic fundamental credential (30 questions / 1 hour) measuring the ability to read, work with, analyze, and communicate with data. |
| **Data Load Editor** | Qlik's environment for writing the load script (Qlik's ETL) that extracts, transforms, and loads data into the associative model. |
| **Green / white / gray** | Qlik's associative selection colors: green = the values you selected, white = values associated (still possible), gray = values excluded (not related) — recolored instantly across the whole app on each selection. |
| **Master items** | Centrally-defined, reusable dimensions, measures, and visualizations defined once and reused everywhere, delivering governed self-service (consistent, approved definitions across apps). |
| **Platform-neutral** | Qlik certification content that applies to both client-managed Qlik Sense and Qlik Cloud, so the credential is portable across deployment models. |
| **Power of gray** | Qlik's distinctive value of seeing what is *not* associated with a selection (the gray, excluded values) — the negative-space insight (absences, gaps) that query-based tools cannot show. |
| **QMC (Qlik Management Console)** | The central console for administering a client-managed Qlik Sense deployment — managing content, access (security rules), reload tasks, and monitoring. |
| **Qlik Cloud** | Qlik's SaaS analytics platform — Qlik-hosted and managed, consumed as a service; the strategic direction alongside client-managed Qlik Sense. |
| **Qlik Sense** | Qlik's modern analytics application, where users build and consume interactive analytics apps, running on the associative engine (client-managed or Qlik Cloud). |
| **QVD** | QlikView Data file — Qlik's optimized binary data format that loads very fast, used as an intermediate layer for efficient, reusable, layered data loading. |
| **Set analysis** | Qlik's expression syntax (`{<...>}`) for defining exactly which set of data an aggregation operates on, independent of or modifying the current selections — enabling comparative analytics (year-over-year, this-vs-all); distinctive and heavily tested. |
| **Streams / spaces** | Containers that group apps and control access — streams (client-managed) and spaces (Qlik Cloud); an app published to a stream/space is visible per users' access to it. |
| **Synthetic key** | An artificial key Qlik creates when two tables share more than one field name — usually a modeling error that bloats the model and confuses associations, avoided by deliberate field naming. |
| **System Administrator (QSSA)** | The Qlik role and expert certification for deploying and governing the platform — the QMC (or Qlik Cloud admin), streams/spaces, security rules, and reload tasks. |
| **Insight Advisor** | Qlik's augmented-analytics assistant — using AI to auto-generate visualizations and insights and answer natural-language questions, complementing manual analysis. |
