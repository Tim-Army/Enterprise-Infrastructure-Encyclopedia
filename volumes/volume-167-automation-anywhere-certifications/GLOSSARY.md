# Volume CLXVII — Glossary

| Term | Definition |
|:---|:---|
| **Advanced Certification** | Automation Anywhere's mainstream developer credential (Certified Advanced Automation Professional, Automation 360) — 60 multiple-choice questions, 2 hours, 80% to pass, 2 attempts, $50 renewal. |
| **Agentic Process Automation (APA)** | Automation Anywhere's evolution of RPA — automation built around AI agents that reason about a goal and decide steps, combined with deterministic bots for the actions. |
| **AI Agent Studio** | The Automation 360 capability for building AI agents and connecting generative-AI models — defining an agent's goal, instructions, and tools, and grounding it on your data. |
| **AI Automation Engineer Certification** | Automation Anywhere's AI/agentic flagship credential — Document Automation, AI Agent Studio, and Automation Co-Pilot; the top tier reflecting the RPA→APA shift. |
| **Attended automation** | Bots that run alongside a person on their desktop, assisting them in real time (front office) — triggered by the human, who stays in control. |
| **Automation 360** | The current Automation Anywhere platform — cloud-native and fully web-based (build and run bots in a browser), the foundation of the Automation Success Platform. |
| **Automation Co-Pilot** | Automation Anywhere's AI assistant — for developers (generate automation logic from natural language in the Bot Creator) and for business users (invoke automations and get AI help in the flow of work). |
| **Bot Creator** | The browser-based development interface where a developer builds a bot by assembling actions, then checks it into the Control Room. |
| **Bot Insight** | Automation Anywhere's analytics — operational metrics (runs, success/failure, exceptions) and business metrics (hours saved, ROI) surfaced on dashboards. |
| **Bot Runner** | A licensed execution device (VM or desktop) where bots actually run — attended (with a person) or unattended (on its own). |
| **Center of Excellence (CoE)** | The team and operating model that scales automation — standards and reuse, governance, a discover→prioritize→build→deploy→measure→improve pipeline, and enablement. |
| **Control Room** | The central, web-based hub of Automation 360 — stores bots, deploys and schedules them to Bot Runners, holds secrets in the Credential Vault, enforces RBAC, and provides audit and monitoring. |
| **Credential Vault** | The Control Room's central, encrypted store of secrets — bots reference a credential by name and the value is injected at runtime, so no password lives in the bot. |
| **Document Automation** | Automation Anywhere's intelligent document processing (IDP, successor to IQ Bot) — AI/ML that classifies documents and extracts fields across varied layouts, with confidence scores and human-in-the-loop correction. |
| **Essentials Certification** | Automation Anywhere's free, foundational credential — building basic bots on Automation 360; the entry point to the program. |
| **Human-in-the-loop** | An automation pattern where a bot does the mechanical work and pauses for a human to review, decide, or approve before continuing — essential for exceptions and judgment. |
| **Process Discovery** | Analyzing how work is actually done (from interactions and logs) to surface the best automation candidates — high-volume, standardized, rules-based tasks — from real evidence. |
| **RBAC (Role-Based Access Control)** | The Control Room's least-privilege model — roles decide who can create, deploy, run, and administer, so a developer builds, an operator deploys, and an admin governs. |
| **Task Bot** | The core automation artifact — the logic that performs a process as an ordered sequence of actions over variables, built in the Bot Creator. |
| **Unattended automation** | Bots that run on their own on dedicated Bot Runners without a human present — scheduled or triggered, processing back-office work at scale (the 24/7 digital workforce). |
| **Automation Success Platform** | Automation Anywhere's unified platform (on Automation 360) for building, running, and governing automation, with AI (Co-Pilot, Document Automation, AI Agent Studio) layered across it. |
