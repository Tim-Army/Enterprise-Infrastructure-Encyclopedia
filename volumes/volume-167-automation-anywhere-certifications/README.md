## Overview

**Automation Anywhere** builds a **digital workforce** — software bots that automate repetitive, rules-based
work — and has pivoted decisively to **Agentic Process Automation**, adding **AI agents** that reason and
generative AI that handles language and unstructured work. Its **Automation Success Platform** (on Automation
360) is cloud-native and web-based, orchestrated from a central **Control Room**. Automation Anywhere sits
alongside the automation platforms this shelf covers ([UiPath CXLIX](../volume-149-uipath-certifications/README.md),
[Pega CLXIV](../volume-164-pega-certifications/README.md)) — its angle is a browser-native platform and a strong
agentic-AI direction.

Chapter 02 covers **the Automation Success Platform** (Automation 360, Control Room, Bot Creators/Runners).
Chapters 03–08 take the discipline: **building bots**, **the Control Room** (deploy, vault, RBAC, govern),
**attended/unattended + Automation Co-Pilot**, **Document Automation** (IDP), **Agentic Process Automation + AI
Agent Studio**, and **Process Discovery, Bot Insight, and the CoE**. Chapter 09 closes on choosing a path, with a
capstone combining IDP, an AI agent, a bot, and human oversight.

A theme runs through it: **build** (bots), **govern** (Control Room), **assist** (Co-Pilot), **read** (Document
Automation), **reason** (agents), and **scale** (discovery + CoE) — the RPA→APA arc from scripting bots to
engineering AI-driven automation.

## The certifications

Three tiers on Automation Anywhere University (training free):

| Tier | Certification |
| --- | --- |
| **Foundational** | Essentials Certification (free) |
| **Advanced** | Advanced Certification — Certified Advanced Automation Professional (Automation 360) |
| **AI / Agentic** | AI Automation Engineer Certification |

**Advanced exam mechanics:** 60 multiple-choice questions · 2 hours · 80% to pass · 2 attempts · $50 renewal.
Masterclasses (learning paths, not exams): Agentic Process Automation Developer, APA Leader, Document Automation.

## What you will be able to do

- Read the Automation Anywhere tiers and the RPA→Agentic Process Automation shift.
- Explain the Automation Success Platform — Automation 360, Control Room, Bot Creators, and Bot Runners.
- Build a Task Bot — actions, variables, recorders, control flow, and reusable subtasks.
- Govern from the Control Room — deploy, work queues, the Credential Vault, RBAC, and audit.
- Choose attended vs unattended, add human-in-the-loop, and use Automation Co-Pilot.
- Process documents with intelligent document processing — extract, confidence, validate, route.
- Build agentic automation with AI Agent Studio — agents that reason, under guardrails and oversight.
- Run a program — Process Discovery, Bot Insight ROI, and a Center of Excellence.

## Prerequisites

- Familiarity with business applications and the idea of automating repetitive work helps.
- A Linux or macOS host with `python3`. **Automation Anywhere certifications** are delivered via Automation
  Anywhere University (free training; Essentials is free, Advanced/AI Automation Engineer are proctored exams).
