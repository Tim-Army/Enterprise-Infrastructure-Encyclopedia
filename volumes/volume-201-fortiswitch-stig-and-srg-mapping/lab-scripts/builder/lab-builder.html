Lab Builder

Volume CCI: pick a platform and options, then get a manifest, a command, and a checklist for the lab machines in Chapter 999. Everything runs in this page. Nothing is sent anywhere.
The Proxmox VE and VMware Workstation scripts have built the lab machines on real hosts. The ESXi, vCenter, VxRail, KVM, and WSL scripts have not been run. The minimum sizes are proposals that still need a test build. Chapters 09 to 14 explain each platform. Experimental flavors have generated, checked files, but few or no machines have been built from them, and Chapter 09 lists what was built. Windows, Linux Mint, and Tiny Core install from an ISO you supply, and Mint and Tiny Core still need a person to run part of the install.
