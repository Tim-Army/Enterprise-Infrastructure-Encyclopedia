Lab Builder

Volume CCI: pick a platform and options, then get a manifest, a command, and a checklist for the lab machines in Chapter 999. Everything runs in this page. Nothing is sent anywhere.
The scripts behind this page have not been run on real hosts, and the minimum sizes are proposals that still need a test build. Chapters 09 to 14 explain each platform. Experimental flavors have generated, checked files but no machine has been built from them. Windows, Linux Mint, and Tiny Core install from an ISO you supply, and Mint and Tiny Core still need a person to run part of the install.
