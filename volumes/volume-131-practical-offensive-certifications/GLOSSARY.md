# Volume CXXXI — Glossary

| Term | Definition |
|:---|:---|
| **Authorization** | Explicit, signed, in-scope permission to test a system — the legal and ethical basis for all offensive work; testing without it is a crime. |
| **Blue team** | The defensive side: monitoring, detection, incident response, hunting, and forensics (HTB CDSA, TCM PSAA/PSAP, INE eSOC/eCIR/eCTHP/eCDFP). |
| **CAPE** | HTB Certified Active Directory Pentesting Expert — advanced AD/Windows attack paths (Kerberos/NTLM/ADCS/trusts). |
| **CDSA** | HTB Certified Defensive Security Analyst — SOC operations, detection, and incident handling. |
| **CPTS** | HTB Certified Penetration Testing Specialist — the intermediate network-pentest flagship (with a commercial-grade report). |
| **COAE / PAPA / eAIS** | The three providers' AI-security certifications (HTB Offensive AI Expert, co-developed with Google; TCM AI Pentest Associate; INE AI Systems Security Specialist). |
| **Detection engineering** | Writing tuned, ATT&CK-mapped rules that catch attacker techniques — turning offensive knowledge into defensive coverage. |
| **eJPT / eCPPT / eWPT / eWPTX / eMAPT** | INE Security (eLearnSecurity) practical certs: Junior Pentester, Certified Professional Pentester, Web, Web eXtreme, Mobile. |
| **Hands-on / practical exam** | A certification assessed by performing tasks in a real lab environment (plus a report), not by multiple-choice questions. |
| **IDOR** | Insecure Direct Object Reference — a broken-access-control flaw where the app trusts an object ID without verifying ownership; fixed by server-side authorization. |
| **Incident Response (IR)** | The lifecycle of handling a confirmed compromise: prepare, detect/analyze, contain, eradicate, recover, lessons learned. |
| **Kerberoasting** | An AD attack requesting service tickets to crack offline; detected via bulk TGS (Event 4769) + RC4, prevented via AES/gMSA/long passwords. |
| **MITRE ATT&CK** | The knowledge base of adversary tactics/techniques used to map detections and hunts. |
| **PNPT** | TCM Practical Network Penetration Tester — a 5-day external+internal engagement plus a professional report (TCM's flagship). |
| **Prompt injection** | An AI/LLM attack where untrusted input overrides the model's instructions; defended by input/output isolation and treating model output as untrusted. |
| **Report** | The engagement deliverable (executive summary, scope, findings with severity/evidence/reproduction, remediation) — what practical exams truly grade. |
| **Rules of Engagement (RoE)** | The agreed scope, exclusions, timing, and stop conditions of an authorized test — the gate no engagement proceeds without. |
| **Threat hunting** | Proactive, hypothesis-driven search for compromises that detections missed (INE eCTHP). |
| **Tiered administration** | An AD design where high-privilege credentials never touch lower-trust systems, structurally breaking lateral-movement paths. |
| **Triage** | Prioritizing alerts by fidelity, asset value, and corroboration to find the few true incidents amid the noise. |
