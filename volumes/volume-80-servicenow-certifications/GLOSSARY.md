# Volume LXXX Glossary

Definitions for terms introduced in **Volume LXXX — ServiceNow Certification Tracks**.
See the [master glossary](../../GLOSSARY.md) for cross-volume terms.

- **ACL (Access Control List)** — ServiceNow's record- and field-level security rule, granting an operation based on role and condition/script.
- **Business Rule** — server-side script that runs on database operations (before/after/async insert/update/delete) to enforce logic.
- **CAD (Certified Application Developer)** — ServiceNow's development certification (GlideRecord scripting, Business Rules, scoped apps, REST).
- **CIS (Certified Implementation Specialist)** — a family of ServiceNow certifications, each covering a product area (ITSM, CSM, HR, VR, SIR, etc.).
- **Client Script** — a script that runs in the browser on form events (onLoad/onChange/onSubmit) for UI behavior.
- **CMA (Certified Master Architect)** — ServiceNow's top architect credential, assessed by multi-day practical evaluation.
- **CMDB (Configuration Management Database)** — the tables (cmdb_ci and children) modeling infrastructure as Configuration Items and relationships.
- **CSA (Certified System Administrator)** — ServiceNow's foundational certification and prerequisite for most others.
- **CTA (Certified Technical Architect)** — ServiceNow's experience-heavy technical-architect credential.
- **Discovery** — the ITOM capability that probes infrastructure via a MID Server to populate the CMDB automatically.
- **Event Management** — the ITOM capability that ingests monitoring alerts and deduplicates/correlates them into actionable alerts.
- **Flow Designer** — ServiceNow's low-code workflow automation tool (trigger → actions), replacing the legacy Workflow editor.
- **GlideRecord** — the server-side API for querying and manipulating table records.
- **GlideSystem (gs)** — the server-side utility API for logging, user context, and helpers.
- **IntegrationHub** — ServiceNow's low-code integration capability, providing pre-built spokes and REST/SOAP actions in Flow Designer.
- **IRM (Integrated Risk Management)** — ServiceNow's governance, risk, and compliance application (formerly GRC), mapping controls to authorities.
- **MID Server** — an on-premises agent used by Discovery, Event Management, and integrations to reach internal systems.
- **Now Assist** — ServiceNow's generative-AI layer (summaries, drafting, code/flow generation, Virtual Agent) applied with guardrails.
- **Now Platform** — ServiceNow's underlying application and workflow platform on which all products run.
- **PDI (Personal Developer Instance)** — a free ServiceNow instance for learning and development.
- **Performance Analytics (PA)** — the capability that snapshots indicators over time to show trends (distinct from point-in-time Reporting).
- **Scoped application** — a self-contained application with its own namespace, tables, and security.
- **Security Incident Response (SIR)** — ServiceNow's SecOps application for the security-incident lifecycle and playbook automation.
- **Service Catalog** — the storefront of requestable items (catalog items) backed by workflows.
- **Update Set** — a container that captures configuration changes for promotion from development to test to production.
- **Vulnerability Response (VR)** — ServiceNow's SecOps application that ingests scanner findings, prioritizes them, and drives remediation.
