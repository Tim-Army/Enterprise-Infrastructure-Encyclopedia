# Volume XLVII Glossary

Definitions for terms used in **Volume XLVII — Oracle Certification Tracks**,
alphabetized. See also the [volume index](INDEX.md) and the
[master glossary](../../GLOSSARY.md) for cross-volume terminology.

**AI Vector Search** — Oracle Database 23ai's native ability to store and query
vector embeddings (e.g., `VECTOR_DISTANCE`), enabling in-database RAG. Used in
Chapters 06 and 07.

**Autonomous Database** — Oracle's self-managing, self-securing, self-repairing
database service (ATP/ADW). Used in Chapters 03 and 07.

**Availability Domain (AD)** — A fault-isolated data center within an OCI region;
Fault Domains isolate further within an AD. Used in Chapter 02.

**CDB / PDB** — The Oracle multitenant model: a Container Database (CDB) hosts
pluggable databases (PDBs). Used in Chapter 07.

**CertView** — Oracle's portal for managing and verifying certifications. Used in
Chapters 01 and 09.

**Cloud Guard** — OCI's cloud-security-posture service that detects
misconfigurations/threats and can auto-remediate. Used in Chapter 05.

**Compartment** — An OCI logical container and IAM boundary for resources,
spanning regions within a tenancy. Used in Chapters 02 and 03.

**DRG (Dynamic Routing Gateway)** — The OCI routing hub used for transit routing
and hybrid connectivity. Used in Chapter 05.

**FastConnect** — A private, dedicated OCI connectivity option (vs Site-to-Site
VPN over the internet). Used in Chapters 03 and 05.

**OCI (Oracle Cloud Infrastructure)** — Oracle's cloud platform and one of the four
certification families. Used throughout.

**Oracle Database 23ai** — The current Oracle Database release, adding AI Vector
Search and JSON Relational Duality. Used in Chapters 06 and 07.

**RAG (Retrieval-Augmented Generation)** — Grounding LLM answers with retrieved
context, on OCI backed by 23ai AI Vector Search. Used in Chapter 06.

**Resource Manager** — OCI's managed Terraform service for infrastructure as code.
Used in Chapter 04.

**Resource principal** — An OCI identity that lets code/functions authenticate to
OCI services without stored keys. Used in Chapters 04 and 06.

**RMAN (Recovery Manager)** — Oracle's backup-and-recovery tool for consistent,
recoverable database backups. Used in Chapter 07.

**T-Few** — OCI Generative AI's parameter-efficient fine-tuning method (few
examples). Used in Chapter 06.

**Transit routing** — A DRG hub-and-spoke pattern for scalable connectivity across
VCNs and on-premises. Used in Chapter 05.

**Vault / KMS** — OCI's managed key and secret service (HSM-backed keys, BYOK).
Used in Chapter 05.

**VCN (Virtual Cloud Network)** — OCI's software-defined network (subnets,
gateways, NSGs). Used in Chapters 02 and 03.

**Year-versioned exam code** — Oracle's convention of encoding the exam refresh
year in a suffix (e.g., 1Z0-1072-26). Used in Chapters 01 and 09.
