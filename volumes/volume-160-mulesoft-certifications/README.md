## Overview

MuleSoft is a leader in **API-led integration** — its **Anypoint Platform** connects applications, data, and
devices by building and managing **APIs**. MuleSoft is **owned by Salesforce** (acquired 2018), so its
certifications are branded **Salesforce Certified MuleSoft** credentials. The core idea is **API-led
connectivity**: composing reusable APIs into an **application network** instead of brittle point-to-point
integrations. MuleSoft is the **integration layer** of the [Salesforce ecosystem (LXXXIII)](../volume-083-salesforce-certifications/README.md).

Chapter 02 covers **API-led connectivity** (the System/Process/Experience three-layer model and the
application network). Chapters 03–08 take the platform: **the Anypoint Platform** (the unified lifecycle),
**designing APIs** (RAML/OAS specs, Design Center, Exchange), **building integrations** (Anypoint Studio,
flows, connectors), **DataWeave** (the transformation language), **deploying and managing** (CloudHub,
Runtime Fabric, API Manager, monitoring), and **hyperautomation and Catalyst** (RPA/IDP/Composer and the
delivery methodology). Chapter 09 closes on choosing a path.

A theme runs through it: **reusable APIs compose into an application network**, turning integration from a
per-project cost into a compounding organizational asset.

## What you will be able to do

- Read the three-family program and its exam mechanics.
- Explain API-led connectivity — System, Process, and Experience APIs and the application network.
- Navigate the Anypoint Platform lifecycle — design, build, deploy, manage.
- Design APIs API-first with RAML/OAS specs, Design Center, and Anypoint Exchange for reuse.
- Build Mule applications — flows of connectors, transformations, routing, and error handling.
- Transform data across formats with DataWeave (map, filter, functional transformation).
- Deploy to CloudHub/Runtime Fabric and govern with API Manager policies and monitoring.
- Apply hyperautomation (RPA/IDP/Composer) and the MuleSoft Catalyst delivery methodology (C4E).
