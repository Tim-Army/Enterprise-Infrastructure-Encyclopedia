# Volume LXX Glossary

Definitions for terms introduced in **Volume LXX — Trellix Certification Tracks**.
See the [master glossary](../../GLOSSARY.md) for cross-volume terms.

- **Access protection** — an ENS Threat Prevention capability that blocks untrusted processes from modifying protected files, registry keys, or processes.
- **Adaptive Threat Protection (ATP)** — ENS's reputation-based dynamic defense, using Global Threat Intelligence and local analysis to allow, contain, or block by risk.
- **Advanced Threat Defense (ATD)** — Trellix's sandboxing appliance that detonates unknown files to produce a malware verdict.
- **Certified Product Specialist** — Trellix Education Services' per-product certification validating install/configure/administer skills.
- **DXL (Data Exchange Layer)** — Trellix's real-time publish/subscribe and request/response messaging fabric for security integration.
- **DLP (Data Loss Prevention)** — Trellix's endpoint and network data-protection product (classifications, rules, incidents).
- **EDR (Endpoint Detection and Response)** — Trellix's detection, hunting, investigation, and response platform.
- **ENS (Endpoint Security)** — Trellix's integrated endpoint protection suite (Threat Prevention, Firewall, Web Control, ATP).
- **ePO (ePolicy Orchestrator)** — Trellix's central management console (System Tree, policies, tasks, tags, reporting, API).
- **Helix** — Trellix's SecOps/SIEM/XDR platform (from FireEye) for ingestion, correlation, and orchestrated response.
- **OpenDXL** — the open-source client and Python SDK for the DXL fabric.
- **Process story** — EDR's causality chain (root process → children → network → impact) for investigation.
- **Reaction** — an EDR response action on an endpoint (isolate/contain, kill process, delete file, collect forensics).
- **System Tree** — ePO's hierarchy of managed systems, organized by group and used for policy assignment.
- **Tag** — an ePO label applied by criteria to group systems dynamically.
- **Threat Prevention** — ENS's anti-malware module (on-access/on-demand scanning, access protection, exploit prevention).
- **Trellix** — the security company formed in 2022 from McAfee Enterprise and FireEye.
- **Trellix Agent** — the endpoint agent that communicates with ePO for policy and event reporting.
- **XDR** — extended detection and response; cross-domain correlation of endpoint, network, and other signals into unified incidents (via Helix).
