# Volume LXXXII Glossary

Definitions for terms introduced in **Volume LXXXII — Alibaba Cloud Certification Tracks**.
See the [master glossary](../../GLOSSARY.md) for cross-volume terms.

- **ACA (Alibaba Cloud Associate)** — Alibaba Cloud's foundational certification level.
- **ACE (Alibaba Cloud Expert)** — Alibaba Cloud's expert, specialized certification level.
- **ACK (Container Service for Kubernetes)** — Alibaba Cloud's managed Kubernetes service.
- **ACP (Alibaba Cloud Professional)** — Alibaba Cloud's professional (advanced) certification level.
- **Anti-DDoS** — Alibaba Cloud's service that mitigates volumetric denial-of-service attacks (Basic/Pro/Premium tiers).
- **Auto Scaling** — the service that adjusts ECS capacity automatically based on demand.
- **Availability Zone (AZ)** — an isolated location within a region; spreading resources across AZs provides high availability.
- **DataWorks** — Alibaba Cloud's data-pipeline orchestration and development platform.
- **ECS (Elastic Compute Service)** — Alibaba Cloud's virtual-machine service.
- **Function Compute** — Alibaba Cloud's serverless, event-driven function service.
- **MaxCompute** — Alibaba Cloud's serverless, petabyte-scale data-warehouse service.
- **OSS (Object Storage Service)** — Alibaba Cloud's object-storage service (buckets, lifecycle, access control).
- **PAI (Platform for AI)** — Alibaba Cloud's machine-learning platform (PAI-Studio, PAI-DSW, PAI-EAS).
- **PolarDB** — Alibaba Cloud's cloud-native database (compute/storage separation, elastic scaling).
- **RAM (Resource Access Management)** — Alibaba Cloud's identity and access-management service (users, roles, JSON policies).
- **RDS (Relational Database Service)** — Alibaba Cloud's managed relational-database service.
- **Realtime Compute** — Alibaba Cloud's Flink-based stream-processing service.
- **Resource Directory** — Alibaba Cloud's multi-account governance structure (management account, OUs, member accounts).
- **Security Center** — Alibaba Cloud's workload-protection service (vulnerability, baseline, intrusion detection).
- **Security group** — a stateful virtual firewall attached to ECS instances.
- **SLB / ALB (Server / Application Load Balancer)** — Alibaba Cloud's load-balancing services.
- **VPC (Virtual Private Cloud)** — Alibaba Cloud's isolated private network, subdivided into vSwitches.
- **vSwitch** — a subnet within a VPC, residing in a single Availability Zone.
- **WAF (Web Application Firewall)** — Alibaba Cloud's HTTP-layer web-application protection service.
