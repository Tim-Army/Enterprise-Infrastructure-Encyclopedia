> The whole Alibaba Cloud certification program in one volume — the ACA/ACP/ACE levels across Cloud
> Computing, Cloud Security, Big Data, Cloud Native, and Machine Learning — on ECS, VPC, OSS, RDS,
> ACK, MaxCompute, and PAI, with hands-on labs, verified against alibabacloud.com.

## Overview

Volume LXXXII maps the **Alibaba Cloud** certification program — the credentials for building on the
leading Asia-Pacific cloud and global hyperscaler. Run by **Alibaba Cloud Academy**, the program has
three levels — **ACA (Associate)**, **ACP (Professional)**, and **ACE (Expert)** — across domains:
**Cloud Computing** (ECS, VPC, OSS, RDS, SLB), **Cloud Security** (Security Center, WAF, Anti-DDoS,
RAM), **Big Data** (MaxCompute, DataWorks), **Cloud Native** (ACK, Function Compute), **Database**,
**Networking**, **DevOps**, and **Machine Learning/AI** (PAI). It joins the encyclopedia's cloud
providers (AWS XVII, Azure XXXIII, Google Cloud XXXIV, Oracle XLVII) and its Cloud & platform cluster.

This is a **certification-tracks** volume, like the other vendor volumes (XXXIX–LXXXI): it maps the
program — the levels and domains — and teaches each with a hands-on walkthrough. Every level and
service area was **verified against alibabacloud.com on 29 July 2026**.

Chapters follow the level ladder:

- **Chapter 01** frames the program — the ACA/ACP/ACE levels, the domains, and Alibaba Cloud Academy.
- **Chapters 02–04** take the **ACA Cloud Computing** and **Cloud Security**: compute/networking; storage/database; security.
- **Chapter 05** takes the **ACP** architecture and best practices.
- **Chapter 06** takes **Big Data** (MaxCompute, DataWorks).
- **Chapter 07** takes **Cloud Native** (ACK, Function Compute).
- **Chapter 08** takes the **ACE** expert level and **Machine Learning** (PAI).
- **Chapter 09** covers certification prep, currency, and career.

Every chapter follows the standard structure defined in
[templates/chapter.md](../../templates/chapter.md) and enforced by
[EDITORIAL_STANDARDS.md](../../EDITORIAL_STANDARDS.md), including per-topic hands-on labs and
knowledge checks.

> **Scope.** Cloud administration is authorized work. The Cloud Security domain (Security Center, WAF,
> Anti-DDoS, RAM) is **defensive** — protecting your own tenancy, never an attack.
