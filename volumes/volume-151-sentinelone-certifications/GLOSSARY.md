# Volume CLI — Glossary

| Term | Definition |
|:---|:---|
| **AI SIEM** | SentinelOne's AI-driven security information and event management built on the Singularity Data Lake, replacing the legacy bolt-on SIEM by unifying detection, hunting, and log analytics on one platform. |
| **Autonomous response** | The on-agent AI stopping a threat immediately and automatically (kill, quarantine, isolate) without waiting for a human or a cloud decision — the only response fast enough for machine-speed attacks, and it works offline. |
| **Behavioral AI** | Detecting threats by what code *does* (inject, encrypt, dump credentials) rather than by matching known-bad file signatures — catching novel and fileless attacks signatures miss. |
| **Detect vs protect mode** | The policy choice between alert-only (detect) and autonomous response (protect). Best practice rolls out in detect mode to tune and add minimal exclusions, then moves to protect once confident. |
| **EDR / EPP** | Endpoint Detection and Response (detect, investigate, respond) and Endpoint Protection Platform (prevent). SentinelOne unifies both in one agent. |
| **Purple AI** | SentinelOne's generative-AI security analyst — a copilot enabling natural-language threat hunting and investigation, amplifying analysts. An amplifier the human validates, not an authority. |
| **Remediation** | Reversing every change an attack made (files, registry, tasks, services). Comprehensive because the Storyline recorded every change — one-click, undoing the whole attack. |
| **RemoteOps** | Remote forensics and response at scale — running scripts, collecting artifacts, and remediating across endpoints from the console without physical access. |
| **Rollback** | Restoring files to their pre-attack state — notably recovering ransomware-encrypted files (Windows VSS-based) — enabling recovery in place without reimaging. |
| **SIREN** | SentinelOne Incident Response Engineer — the flagship practical certification (~45 hours of training, multiple-choice plus scenario simulations) validating hands-on incident response on the platform. |
| **Singularity Platform** | SentinelOne's unified platform spanning Endpoint, Identity, Cloud, XDR, the Data Lake / AI SIEM, and Purple AI — unified by behavioral AI, Storyline, and rollback. |
| **Storyline** | The autonomous correlation of related endpoint events into a single attack narrative in real time — the analyst investigates one story instead of stitching hundreds of alerts, cutting MTTR and alert fatigue. |
| **THP** | Threat Hunting Professional — the advanced certification for proactive, hypothesis-driven hunting, anomaly detection, and SIEM/SOAR integration. |
| **Threat hunting** | Proactively searching for threats that have not triggered an alert, on the hypothesis a quiet attacker is present — querying rich endpoint telemetry to surface them. |
| **XDR** | Extended Detection and Response — extending detection and Storyline correlation across endpoint, identity, cloud, and network, so a cross-surface attack becomes one narrative instead of siloed alerts. |
