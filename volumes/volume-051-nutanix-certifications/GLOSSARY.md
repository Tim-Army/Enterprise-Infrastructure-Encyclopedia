# Volume LI Glossary

Definitions for terms used in **Volume LI — Nutanix Certification Tracks**,
alphabetized. See also the [volume index](INDEX.md) and the
[master glossary](../../GLOSSARY.md) for cross-volume terminology.

**acli (Acropolis CLI)** — The command-line interface for AHV/Acropolis operations
(VMs, networks, hosts). Used in Chapters 02–03, 08.

**AHV** — Nutanix's native KVM-based hypervisor. Used throughout.

**AOS** — Acropolis Operating System, the distributed storage/compute fabric of a
Nutanix cluster. Used in Chapters 01–02.

**Community Edition (CE)** — The free version of Nutanix AOS/AHV for learning and
practice. Used in Chapter 01.

**Data Lens** — Nutanix's storage analytics and ransomware-detection service for
Unified Storage. Used in Chapter 06.

**Flow** — Nutanix's network security (microsegmentation) and Flow Virtual Networking
(overlay VPCs). Used in Chapters 03 and 08.

**LCM (Life Cycle Manager)** — Prism's tool for inventorying and upgrading firmware
and software. Used in Chapters 02 and 06.

**NC2 (Nutanix Cloud Clusters)** — AOS/AHV running on bare-metal public-cloud
instances (AWS/Azure), managed via the NC2 console. Used in Chapter 07.

**ncli (Nutanix CLI)** — The command-line interface for cluster-level operations.
Used in Chapters 02–03, 06, 08.

**NDB (Nutanix Database Service)** — Nutanix's DBaaS (formerly Era) for provisioning
and managing databases with Time Machine. Used in Chapter 05.

**Prism Element / Prism Central** — Per-cluster management (Element) and multi-cluster
management (Central). Used in Chapter 02.

**Protection domain** — A group of entities replicated together for data protection
(async/NearSync/Metro). Used in Chapter 08.

**RCAR** — Requirements, Constraints, Assumptions, Risks — the analysis captured in a
design consultation. Used in Chapter 09.

**Self-Service (Calm)** — Nutanix's application automation/self-service with
blueprints, runbooks, and Projects. Used in Chapter 04.

**Storage container** — A logical storage entity on a storage pool with efficiency
settings (compression, dedup, erasure coding). Used in Chapters 03 and 08.

**Time Machine** — NDB's SLA-driven snapshot/point-in-time engine enabling clones and
recovery. Used in Chapter 05.

**Unified Storage (NUS)** — Nutanix Files (SMB/NFS), Objects (S3), and Volumes
(iSCSI). Used in Chapter 06.

**X-Play** — Nutanix's low-code operational automation (Playbooks: triggers +
actions). Used in Chapter 04.
