# Volume CLXXIII Glossary

Definitions for terms introduced in **Volume CLXXIII — Integrated Master
Schedule (IMS)**. See the [master glossary](../../GLOSSARY.md) for cross-volume
terms.

- **Actual cost (AC, ACWP)** — the cost actually incurred for the work performed by the status date.
- **Baseline** — a frozen copy of the approved schedule (dates, durations, work, and time-phased cost) used to measure performance.
- **Baseline change request (BCR)** — the formal, approved request required to change a baseline.
- **Baseline Execution Index (BEI)** — tasks actually completed divided by tasks baselined to complete by the status date.
- **Basis of estimate** — the recorded source and reasoning behind a duration or cost estimate.
- **Control account** — a WBS element managed by one control account manager (CAM) with a defined budget and schedule.
- **Critical path** — the longest chain of dependent tasks through a schedule, which determines the earliest possible finish.
- **Critical Path Length Index (CPLI)** — (remaining critical path length plus total float to the baseline finish) divided by remaining critical path length.
- **Criticality index** — in a schedule risk analysis, the share of simulations in which a task was on the critical path.
- **Data date (status date)** — the date as of which progress is recorded in a status cycle.
- **DCMA 14-point assessment** — a set of 14 Defense Contract Management Agency metrics used to screen schedule health.
- **Deadline** — a target date that flags a late finish without constraining the task's scheduled dates.
- **Earned schedule (ES)** — the time at which the current earned value was planned to be earned, used to compute time-based schedule variance and SPI(t).
- **Earned value (EV, BCWP)** — the budgeted value of the work actually performed by the status date.
- **Free float** — how long a task can slip without delaying any successor.
- **Hard constraint** — a constraint (Must Start On, Must Finish On, Start No Later Than, Finish No Later Than) that can override network logic.
- **Integrated master plan (IMP)** — an event-based plan of program events, the accomplishments each requires, and the criteria that prove them, without dates.
- **Integrated master schedule (IMS)** — a single networked schedule of all program work, integrated with the IMP, the WBS, and earned value.
- **IPMDAR** — the Integrated Program Management Data and Analysis Report (DI-MGMT-81861), the DoD data item for cost and schedule deliverables, including the native IMS file and the Schedule Performance Dataset.
- **Lag / lead** — a positive or negative delay applied to a relationship between two tasks.
- **Level of effort (LOE)** — support work, such as program management, that does not produce discrete deliverables and must not drive logic.
- **Merge bias** — the tendency of a task fed by several parallel paths to start later than any single path suggests, because it waits for the latest.
- **Open end** — a task with no predecessor or no successor, other than the project start and finish milestones.
- **Out-of-sequence progress** — work recorded on a task before its predecessors are complete.
- **Over target baseline (OTB) / over target schedule (OTS)** — a formally approved re-plan when a program can no longer perform against its baseline.
- **Performance measurement baseline (PMB)** — the total time-phased budget plan against which earned value performance is measured.
- **Planned value (PV, BCWS)** — the budgeted value of the work scheduled to be performed by the status date.
- **Planning package** — far-term work held as a budgeted block until it is planned in detail.
- **Progress override / retained logic** — the two ways a scheduler treats the remaining work of an out-of-sequence task: ignoring or honoring its predecessors.
- **Rolling wave planning** — converting planning packages into detailed work packages as the work approaches.
- **Schedule margin** — a visible, management-owned buffer placed before a committed date to absorb risk.
- **Schedule Performance Dataset (SPD)** — the structured schedule data delivered under the IPMDAR.
- **Schedule risk analysis (SRA)** — a simulation of the schedule using ranges and risk events to estimate the probability of meeting dates.
- **SPI / CPI** — the schedule performance index (EV ÷ PV) and cost performance index (EV ÷ AC).
- **Total float** — how long a task can slip without delaying the project finish.
- **Work breakdown structure (WBS)** — a product-oriented hierarchical decomposition of the program's total scope.
- **Work package** — near-term work planned in detail as scheduled, budgeted tasks within a control account.
- **XER** — Primavera P6's native exchange file format.
