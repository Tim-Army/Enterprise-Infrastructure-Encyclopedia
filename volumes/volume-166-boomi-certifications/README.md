## Overview

**Boomi** is the **connective tissue** of the enterprise — the iPaaS pioneer whose low-code platform wires
together SaaS apps, on-premises systems, databases, trading partners, and people. Where a data-management
platform moves and governs data, Boomi **integrates everything** quickly and visually, and runs it on the
**Atom** runtime wherever the data lives. Boomi sits beside the integration and data platforms this shelf covers
([MuleSoft CLX](../volume-160-mulesoft-certifications/README.md),
[Informatica CLXV](../volume-165-informatica-certifications/README.md),
[SAP CXLIV](../volume-144-sap-certifications/README.md)) — the low-code layer that connects them.

Chapter 02 covers **the Boomi Enterprise Platform** (unified, low-code iPaaS). Chapter 03 covers **Atoms,
Molecules, and Atom Clouds** (the runtime). Chapters 04–08 take the services and roles: **building integrations**
(the flagship developer track), **API Management**, **Data Hub** (MDM), **B2B/EDI and Flow**, and **administration
and architecture** (plus Boomi AI). Chapter 09 closes on choosing a path, with a capstone tracing one order
across the whole platform.

A theme runs through it: **connect** (integration), **expose** (APIs), **master** (Data Hub), **exchange**
(EDI), **involve people** (Flow), and **operate** (admin/architecture) — one low-code platform, one runtime.

## The certifications

Organized by service/role, mostly Associate → Professional:

| Track | Certifications |
| --- | --- |
| **Integration Developer** | Associate Integration Developer · Professional Integration Developer |
| **Administrator** | Associate Administrator · Professional Windows Operational Administrator · Professional Linux Operational Administrator |
| **Architect** | Associate Integration Architect · Associate Runtime Architect |
| **API Management** | Professional API Design · Professional API Management |
| **Data Hub (MDM)** | Associate Data Hub · Professional Data Hub Developer |
| **Flow** | Associate Flow Essentials |
| **B2B/EDI** | Associate EDI for X12 |

**Mechanics:** open-book and open-platform · no time limit · multiple-choice/multiple-response + a practical
section · course-backed · **$125** per exam. **Boomi AI** (Companion, Agentstudio, Boomi GPT) is training-only.

## What you will be able to do

- Read the Boomi tracks and the Associate → Professional progression, and the open-book/open-platform format.
- Explain the Boomi Enterprise Platform — a unified, low-code iPaaS connecting apps, data, people, and devices.
- Choose runtimes — Atom, Molecule, and Atom Cloud — and place them for residency, HA, and connectivity.
- Build an integration process — shapes, connectors, profiles, maps, and error handling.
- Publish and govern APIs — gateways, policies, and the API Control Plane against sprawl.
- Master data in Data Hub — models, match rules, golden records, and contribute-and-publish.
- Exchange EDI with trading partners (X12) and build low-code Flow workflows with people in the loop.
- Administer and architect Boomi — environments, deployment, monitoring, topology, and Boomi AI.

## Prerequisites

- Familiarity with applications, data, and the idea of connecting systems helps.
- A Linux or macOS host with `python3`. **Boomi certifications** are delivered via `train.boomi.com`
  (self-paced courses + open-book, open-platform exams; $125 each).
