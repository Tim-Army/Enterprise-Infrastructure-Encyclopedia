## Overview

**Informatica** is the plumbing and governance of the enterprise data estate — the vendor whose tools **move**,
**cleanse**, **master**, **govern**, and **catalog** data for large organizations. If integration moves data
and analytics consume it, Informatica is the layer that makes the data **integrated, trustworthy, governed, and
discoverable** in between. Its cloud platform, **IDMC (the Intelligent Data Management Cloud)**, is a single
environment of **separately-licensed but integrated modules** sharing one **metadata fabric** and one AI engine,
**CLAIRE**. Informatica sits beside the cloud data platforms and BI tools this shelf covers
([Snowflake XLIX](../volume-049-snowflake-certifications/README.md),
[Databricks XLVIII](../volume-048-databricks-certifications/README.md),
[Tableau CLIV](../volume-154-tableau-certifications/README.md),
[MuleSoft CLX](../volume-160-mulesoft-certifications/README.md)) — the data-management layer beneath them.

Chapter 02 covers **IDMC** (the modular platform, the metadata fabric, Secure Agents, and CLAIRE). Chapters
03–08 take the modules: **Cloud Data Integration** (the core ETL/ELT engine), **from PowerCenter to the cloud**
(the legacy engine and its modernization), **Cloud Application Integration** (real-time), **Cloud Data Quality**
(trustworthy data), **Master Data Management** (the golden record), and **Data Governance and Catalog** (knowing
and governing your data). Chapter 09 closes on choosing a path, with a capstone that traces one dataset through
the whole platform.

A theme runs through it: **integrate** (CDI/CAI), **trust** (Data Quality), **master** (MDM), and **govern**
(CDGC) — the full life cycle that turns scattered source data into data an enterprise can rely on.

## The certifications

Two tiers across the IDMC modules and PowerCenter:

| Tier / module | Certifications |
| --- | --- |
| **Cloud Data Integration (CDI)** | Cloud Data Integration Developer, Professional (+ Practitioner) |
| **Cloud Application Integration (CAI)** | Cloud Application Integration Developer, Professional (+ Practitioner) |
| **Cloud Data Quality** | Cloud Data Quality, Professional (+ Practitioner) |
| **Master Data Management (MDM)** | MDM Developer · MDM Administrator · MDM SaaS (+ Practitioner) |
| **Cloud Data Governance & Catalog (CDGC)** | Cloud Data Governance & Catalog, Professional (+ Practitioner) |
| **PowerCenter (on-prem)** | Data Integration Developer · Administrator; PowerCenter Cloud Edition (CDI-PC) |
| **Modernization** | PC to CDI Modernization Implementation Practitioner |

**Mechanics:** Professional exams are **70%** to pass, **90 minutes**, backed by a matching training course, and
**release-dated** (versioned to a platform release). Practitioner credentials are implementation-focused with a
**two-year** validity.

## What you will be able to do

- Read the Informatica program — the Professional and Practitioner tiers and the module-to-certification map.
- Explain IDMC — the modular platform, the metadata fabric, Secure Agents, and CLAIRE.
- Build a Cloud Data Integration mapping — source, transformations, target — and run it as a task.
- Modernize PowerCenter to the cloud — the object model, the CDI correspondence, and wave-based migration.
- Orchestrate real-time application integration — processes, service connectors, and event triggers.
- Make data trustworthy — profile, cleanse, standardize, validate, and score with Cloud Data Quality.
- Build a golden record — match, merge, survivorship, and stewardship with MDM.
- Govern and catalog data — catalog, lineage, glossary, and CLAIRE-style PII classification.

  University; Professional exams are release-dated and course-backed.
