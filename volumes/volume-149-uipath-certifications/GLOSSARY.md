# Volume CXLIX — Glossary

| Term | Definition |
|:---|:---|
| **Agentic automation** | Automation that adds AI **agents** — which reason, decide, and act on ambiguous inputs — to deterministic robots and humans, orchestrating all three. The direction UiPath and the industry have moved, and the subject of the Agentic Automation certifications. |
| **Attended robot** | A robot that runs on a person's desktop, triggered by them, working alongside them in real time (e.g. a call-center helper). Contrast unattended. |
| **Automation Catalysts** | A UiPath badge awarded to professionals holding multiple certifications — a cross-functional, versatile-expertise signal. |
| **Center of Excellence (CoE)** | The central team that governs automation across an organization: standards, Orchestrator, the automation pipeline, and enabling business units to automate safely. Why the certification program is role-based. |
| **Communications Mining** | UiPath's ML capability for understanding and categorizing unstructured **messages** (email, tickets, chat) at scale — intent and routing. Paired with Document Understanding in the Specialized AI Professional. |
| **Confidence score** | An intelligent-document-processing model's stated certainty about an extraction, used to set a threshold: above it, process automatically (straight-through); below it, route to a human. |
| **Document Understanding** | UiPath's intelligent document processing (IDP): ML models that extract, classify, and process data from layout-varying, unstructured documents. |
| **Orchestrator** | The management server that deploys, schedules, queues, monitors, and governs robots, and stores shared assets and credentials — the enterprise control plane that makes automation more than a script. |
| **Queue** | An Orchestrator structure holding work as transaction items that a pool of robots pulls from in parallel — scaling throughput and providing per-item status, retry, and crash recovery. |
| **REFramework** | Robotic Enterprise Framework — UiPath's standard, robust template for unattended transaction processing, baking in a state machine, retries, business-vs-application exception handling, logging, and recovery. |
| **Robot** | The execution engine that performs an automation. **Attended** (on a person's desktop, user-triggered) or **unattended** (headless, scheduled/automatic). |
| **Role-based program** | UiPath's certification model — certifications aligned to real automation-team roles (developer, business analyst, architect, AI, testing, agentic) rather than one linear ladder, each at Associate or Professional level. |
| **RPA** | Robotic Process Automation — software robots automating repetitive, rule-based tasks by operating applications like a person. Deterministic: same input, same action. UiPath's origin, now extended by agentic automation. |
| **Selector** | A structured description of a UI element (type, attributes, position) that a robot uses to find it. Robust selectors key on stable attributes and wildcard variable parts; brittle ones depend on position and break on UI change. |
| **Straight-through processing (STP)** | Processing an item fully automatically, with no human — for extractions above the confidence threshold. The STP rate is the key IDP metric, balanced against auto-error. |
| **Studio** | UiPath's visual, low-code design environment where developers build automations as workflows of activities. |
| **Unattended robot** | A robot that runs headless on a server, triggered by a schedule or event with no human present — for high-volume, lights-out back-office work. |
