# Volume LXXXIII Glossary

Definitions for terms introduced in **Volume LXXXIII — Salesforce Certification Tracks**.
See the [master glossary](../../GLOSSARY.md) for cross-volume terms.

- **Administrator (ADM-201)** — Salesforce's flagship administrator certification.
- **Agentforce** — Salesforce's platform for building, grounding, and operating AI agents that act in the org.
- **Apex** — Salesforce's server-side, Java-like programming language (classes and triggers).
- **Application Architect** — a Salesforce architect credential earned via several exams covering the data model and sharing at scale.
- **Bulkification** — writing Apex to operate on collections of records (not one at a time) to respect governor limits.
- **CTA (Certified Technical Architect)** — Salesforce's pinnacle certification, assessed by a board review.
- **Data Cloud** — Salesforce's data platform that unifies and harmonizes customer data, used to ground AI agents.
- **Flow** — Salesforce's visual, low-code automation engine (Flow Builder).
- **Governor limits** — Salesforce's per-transaction resource limits (e.g., SOQL queries, DML statements) enforced in the multi-tenant platform.
- **Lightning Web Component (LWC)** — Salesforce's modern, standards-based web-component UI framework.
- **Lookup relationship** — a loose reference between two objects.
- **Master-detail relationship** — a tight parent-child relationship where the child depends on the parent and inherits sharing (and supports rollups).
- **Org-Wide Defaults (OWD)** — the baseline record-access setting per object (Private, Public Read Only, Public Read/Write).
- **Permission set** — an additive grant of permissions layered on top of a profile.
- **Platform App Builder** — Salesforce's declarative app-building certification.
- **Platform Developer I/II** — Salesforce's programmatic development certifications (Apex, LWC).
- **Profile** — a user's baseline set of permissions (one per user).
- **Record type** — a variation of an object for a business process, with its own layout and picklist values.
- **Role hierarchy** — the structure that grants managers access to records owned by their subordinates.
- **Sharing rule** — a rule that opens record access laterally to a group or role beyond the hierarchy.
- **SOQL / SOSL** — Salesforce Object Query Language (record queries) and Salesforce Object Search Language (cross-object search).
- **System Architect** — a Salesforce architect credential covering integration, identity, and deployment.
- **Trailhead** — Salesforce's free, gamified learning platform with hands-on Playgrounds.
- **Validation rule** — a rule that blocks a record save when a condition is violated, enforcing data quality.
