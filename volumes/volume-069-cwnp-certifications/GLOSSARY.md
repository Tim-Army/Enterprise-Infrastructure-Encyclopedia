# Volume LXIX Glossary

Definitions for terms introduced in **Volume LXIX — CWNP Certification Tracks**.
See the [master glossary](../../GLOSSARY.md) for cross-volume terms.

- **802.1X / EAP** — the port-based authentication framework (802.1X) and its Extensible Authentication Protocol methods (EAP-TLS, PEAP, EAP-TTLS) used for enterprise Wi-Fi.
- **4-way handshake** — the EAPOL exchange that derives the per-session PTK (and installs the GTK) after authentication.
- **BSS / ESS** — Basic Service Set (one AP and its clients) and Extended Service Set (one SSID across many APs for roaming).
- **CWNA** — Certified Wireless Network Administrator; CWNP's foundation certification (exam CWNA-109).
- **CWSP / CWAP / CWDP** — the professional Wi-Fi certifications: Security, Analysis, and Design.
- **CWISA / CWICP / CWIIP / CWIDP** — the professional IoT-track certifications (Solutions Administrator, Connectivity, Integration, Design).
- **CWNE / CWISE** — the expert-level certifications (Certified Wireless Network Expert for Wi-Fi; Certified Wireless IoT Solutions Expert).
- **CWSS / CWTS** — the entry-level certifications (Sales Specialist; Technology Specialist).
- **dBm** — decibels relative to 1 milliwatt; the standard RF power unit.
- **EIRP** — Effective Isotropic Radiated Power; transmit power minus cable loss plus antenna gain, capped by regulation.
- **FSPL** — Free-Space Path Loss; the signal attenuation over distance and frequency.
- **Link budget** — the sum of gains and losses predicting received signal versus receiver sensitivity.
- **Monitor mode** — a capture mode in which a radio records all 802.11 frames on a channel for analysis.
- **PMF (802.11w)** — Protected Management Frames; protects management frames against deauth/disassoc attacks (mandatory in WPA3).
- **Radiotap** — the capture header carrying per-frame RF metadata (RSSI, data rate, channel).
- **SAE** — Simultaneous Authentication of Equals; WPA3-Personal's handshake, resistant to offline dictionary attacks.
- **Site survey** — predictive (modeled), passive (measured), or active (associated) assessment of the RF environment.
- **Wi-Fi 6/6E (802.11ax)** — the generation adding OFDMA, MU-MIMO, BSS coloring, and (6E) the 6 GHz band.
- **Wi-Fi 7 (802.11be)** — the generation adding 320 MHz channels, 4K-QAM, and Multi-Link Operation (MLO).
- **WIPS** — Wireless Intrusion Prevention System; detects rogue APs and wireless attacks.
- **WMM** — Wi-Fi Multimedia; the QoS mechanism prioritizing voice/video access categories.
- **WPA2 / WPA3** — the Wi-Fi security certifications; WPA3 adds SAE and mandatory PMF.
