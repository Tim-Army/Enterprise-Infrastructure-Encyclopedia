# Volume LXXXIX — GitHub Certification Tracks

> The whole GitHub certification program in one volume — Foundations, Actions, Advanced Security (GHAS),
> Administration, and Copilot — across Git, GitHub collaboration, CI/CD, application security, platform
> administration, and AI pair programming, with hands-on `git`, `gh` CLI, and Actions labs, verified
> against docs.github.com.

## Overview

Volume LXXXIX maps the **GitHub** certification program — the credentials for developing, automating,
securing, and administering software on the world's largest development platform. GitHub offers five
certifications: **GitHub Foundations** (Git and GitHub collaboration), **GitHub Actions** (workflow
automation and CI/CD), **GitHub Advanced Security (GHAS)** (code, secret, and dependency scanning),
**GitHub Administration** (organization and enterprise management), and **GitHub Copilot** (AI pair
programming). This volume opens the encyclopedia's DevOps & observability cluster.

This is a **certification-tracks** volume, like the other vendor volumes (XXXIX–LXXXVIII): it maps the
program — the credentials and the skills measured — and teaches each with a hands-on walkthrough. Every
certification and exam detail was **verified against docs.github.com and GitHub's certification resources
on 29 July 2026** (the About GitHub Certifications docs and the registration pages; third-party
exam-dump sites were excluded as sources).

Chapters follow the certification ladder:

- **Chapter 01** frames the program — the five certifications, the $99 PSI-proctored exams, the skills measured, and free GitHub learning resources.
- **Chapters 02–03** take **GitHub Foundations** — Git and repositories, then collaboration.
- **Chapters 04–05** take **GitHub Actions** — workflows, then CI/CD, secrets, and security hardening.
- **Chapter 06** takes **GitHub Advanced Security** — CodeQL code scanning, secret scanning, and Dependabot.
- **Chapter 07** takes **GitHub Administration** — organizations, enterprises, teams, policies, and SSO.
- **Chapter 08** takes **GitHub Copilot** — responsible AI, features, prompt engineering, and privacy.
- **Chapter 09** covers **certification prep, currency, and career**.

Every chapter follows the standard structure defined in
[templates/chapter.md](../../templates/chapter.md) and enforced by
[EDITORIAL_STANDARDS.md](../../EDITORIAL_STANDARDS.md), including per-topic hands-on labs and
knowledge checks.

> **Scope.** GitHub development, automation, security, and administration are authorized platform work —
> building, automating, securing, and managing your own repositories and organizations. The Advanced
> Security material (code, secret, and dependency scanning) is framed as defensive protection of your
> own code, and the Copilot material as responsible, privacy-aware AI use.
