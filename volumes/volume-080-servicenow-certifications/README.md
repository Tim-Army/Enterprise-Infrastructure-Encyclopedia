## Overview

Volume LXXX maps the **ServiceNow** certification program — the credentials for administering,
developing, and architecting on the **Now Platform**, ServiceNow's enterprise digital-workflow
platform spanning IT, security, customer, and HR service management plus low-code development. The
program runs from the foundational **Certified System Administrator (CSA)** through the **Certified
Application Developer (CAD)** and the large family of **Certified Implementation Specialist (CIS)**
product credentials to the **Certified Technical Architect (CTA)** and **Certified Master Architect
(CMA)** tiers, with emerging **Now Assist (GenAI)** micro-certifications. It opens the encyclopedia's
Cloud & platform cluster alongside the cloud providers (AWS XVII, Azure XXXIII, GCP XXXIV, Oracle
XLVII) and Salesforce (LXXXIII).

This is a **certification-tracks** volume, like the other vendor volumes (XXXIX–LXXIX): it maps the
program — the credentials and product areas — and teaches each with a hands-on walkthrough. Every
credential and platform area was **verified against servicenow.com on 28 July 2026**.

Chapters follow the credential ladder:

- **Chapter 01** frames the program — the CSA→CAD/CIS→CTA/CMA structure, the Now Platform, and the PDI.
- **Chapters 02–03** take the **CSA**: platform foundations, then data and security.
- **Chapter 04** takes the **CAD**: application development.
- **Chapters 05–07** take the **CIS** specializations: ITSM/ITOM; CSM/HR/workflow; Security Operations/GRC.
- **Chapter 08** covers **Integration, Performance Analytics, and Now Assist**.
- **Chapter 09** covers the **CTA/CMA** architect tiers, currency, and career.

Every chapter follows the standard structure defined in
[templates/chapter.md](../../templates/chapter.md) and enforced by
[EDITORIAL_STANDARDS.md](../../EDITORIAL_STANDARDS.md), including per-topic hands-on labs and
knowledge checks.

> **Scope.** ServiceNow administration is authorized platform work. The Security Operations content
> (Vulnerability Response, Security Incident Response) is **defensive** — orchestrating detection,
> prioritization, and response workflows on an authorized instance, never an attack.
