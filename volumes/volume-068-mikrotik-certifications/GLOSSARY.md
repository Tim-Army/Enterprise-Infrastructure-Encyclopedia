# Volume LXVIII Glossary

Definitions for terms introduced in **Volume LXVIII — MikroTik Certification Tracks**.
See the [master glossary](../../GLOSSARY.md) for cross-volume terms.

- **CAPsMAN** — Controlled Access Point system Manager; centralizes configuration of a fleet of RouterOS access points (CAPs).
- **CHR (Cloud Hosted Router)** — the free RouterOS virtual machine for x86/hypervisors, used for labs and virtual deployments.
- **EoIP** — Ethernet over IP; a MikroTik tunnel that bridges Layer-2 across an IP network.
- **Hotspot** — RouterOS captive-portal access with a login page and usage/time limits.
- **Mangle** — the RouterOS firewall facility that marks connections and packets for later matching (queues, routing).
- **Masquerade** — a RouterOS source-NAT action that hides a LAN behind the router's WAN address.
- **MTCNA** — MikroTik Certified Network Associate; the foundation certificate and prerequisite for all others.
- **MTCRE / MTCTCE / MTCWE / MTCUME / MTCINE / MTCSE / MTCSWE / MTCIPv6E** — the specialist certificates (Routing, Traffic Control, Wireless, User Management, Inter-networking, Security, Switching, IPv6).
- **MTCEWE** — MikroTik Certified Enterprise Wireless Engineer.
- **Queue tree** — a hierarchical RouterOS QoS structure that shapes traffic by packet mark (often with HTB).
- **RADIUS** — the AAA protocol RouterOS uses as a client; MikroTik's **User Manager** is a RADIUS server.
- **RouterBOARD** — MikroTik's hardware platform running RouterOS.
- **RouterOS** — MikroTik's routing/switching/wireless/security operating system (v6 and v7).
- **REST API** — RouterOS v7's HTTPS/JSON API (`/rest/...`) for programmatic management.
- **Simple queue** — a per-target bandwidth limit in RouterOS.
- **User Manager** — MikroTik's RADIUS server for centralized user, profile, and accounting management.
- **VPLS** — Virtual Private LAN Service; a Layer-2 VPN over MPLS.
- **WinBox** — MikroTik's Windows/GUI management tool for RouterOS.
