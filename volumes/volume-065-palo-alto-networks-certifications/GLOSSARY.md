# Volume LXV Glossary

Definitions for terms introduced in **Volume LXV — Palo Alto Networks Certification Tracks**.
See the [master glossary](../../GLOSSARY.md) for cross-volume terms.

- **App-ID** — the PAN-OS technology that identifies the application in traffic regardless of port or protocol, so policy is written on applications.
- **CIEM (Cloud Infrastructure Entitlement Management)** — CNAPP capability that analyzes effective cloud permissions and flags over-privileged identities.
- **CNAPP (Cloud-Native Application Protection Platform)** — a unified platform combining CSPM, CWPP, CIEM, and IaC scanning (Prisma/Cortex Cloud).
- **Content-ID** — the PAN-OS engine that inspects allowed traffic for threats, URLs, and sensitive data.
- **Cortex XDR** — Palo Alto's extended detection and response platform: stitched, cross-source incidents with behavioral analytics.
- **Cortex XSIAM** — the AI-driven security operations platform (next-generation SIEM) that unifies data and reduces alerts to incidents.
- **Cortex XSOAR** — the security orchestration, automation, and response platform built on playbooks and integrations.
- **CSPM / CWPP** — Cloud Security Posture Management (misconfiguration/compliance) and Cloud Workload Protection Platform (host/container/serverless).
- **NGFW (Next-Generation Firewall)** — Palo Alto's PAN-OS firewall with single-pass App-ID/User-ID/Content-ID inspection.
- **PAN-OS** — the operating system of Palo Alto firewalls, using single-pass parallel processing.
- **Panorama** — Palo Alto's centralized management platform for firewalls (templates, device groups, logging).
- **pan-os-python** — Palo Alto's Python SDK for the PAN-OS/Panorama API.
- **Prisma Access** — Palo Alto's cloud-delivered Security Service Edge (SSE), the security half of SASE.
- **Prisma Cloud / Cortex Cloud** — Palo Alto's CNAPP for cloud security posture, workloads, identity, and IaC.
- **Prisma SD-WAN** — Palo Alto's application-aware SD-WAN fabric (ION devices, central orchestration).
- **Role-based framework** — the 2025 restructure of Palo Alto certifications into levels (Foundational/Professional/Specialist/Architect) and tracks (Network Security/Security Operations/Cloud Security), retiring the legacy code-based exams.
- **RQL (Prisma Cloud Query Language)** — the query language for searching cloud configuration, network, and audit data in Prisma/Cortex Cloud.
- **SASE (Secure Access Service Edge)** — the convergence of SD-WAN (network) and SSE (security) delivered from the cloud.
- **Security Profiles** — PAN-OS threat-prevention profiles (Antivirus, Anti-Spyware, Vulnerability Protection, URL Filtering, WildFire, File Blocking, Data Filtering) attached to allow rules.
- **User-ID** — the PAN-OS technology that maps traffic to user identity for identity-based policy.
- **XQL (Cortex Query Language)** — the query language for hunting, detection, and correlation in Cortex XDR and XSIAM.
- **ZTNA (Zero Trust Network Access)** — per-application access granted on identity and device posture, not network location.
