# Volume LXXIX Glossary

Definitions for terms introduced in **Volume LXXIX — Qualys Certification Tracks**.
See the [master glossary](../../GLOSSARY.md) for cross-volume terms.

- **CAR (Custom Assessment and Remediation)** — Qualys's capability to run custom scripts via the Cloud Agent to assess or remediate conditions not checked natively.
- **Cloud Agent** — a lightweight Qualys agent installed on a host that continuously reports inventory, vulnerabilities, and configuration, working off-network.
- **Container Security** — Qualys's product for scanning container images (in registries/CI-CD) and monitoring running containers.
- **CSAM (CyberSecurity Asset Management)** — Qualys's complete asset inventory with enrichment and External Attack Surface Management.
- **EASM (External Attack Surface Management)** — discovery of internet-facing assets an organization may not know it owns.
- **EDR (Endpoint Detection and Response)** — Qualys's endpoint threat detection and response, using the same Cloud Agent.
- **FIM (File Integrity Monitoring)** — Qualys's monitoring of critical files, directories, and registry keys for unauthorized change.
- **Passive network sensor** — a Qualys sensor that discovers unmanaged assets by observing network traffic.
- **Patch Management** — Qualys's capability to correlate vulnerabilities to patches and deploy them from the same platform.
- **Policy Compliance (PC)** — Qualys's credentialed configuration-compliance assessment against benchmark and mandate controls.
- **QID (Qualys ID)** — Qualys's identifier for a specific vulnerability or compliance check (analogous to a plugin).
- **QFlow (Qualys Flow)** — Qualys's no-code, visual workflow-automation engine.
- **QQL (Qualys Query Language)** — Qualys's unified query language for searching assets, vulnerabilities, and compliance across the platform.
- **Qualys Cloud Platform** — Qualys's single SaaS backend into which all applications and sensor data flow.
- **Scanner appliance** — a virtual or physical Qualys network scanner for reachable targets, including credentialed scans.
- **TotalAppSec** — Qualys's web application and API security (DAST) offering.
- **TotalCloud** — Qualys's cloud security (CSPM/CNAPP) offering for cloud posture, workload scanning, and toxic-combination analysis.
- **Toxic combination** — a set of individually-minor issues that together form a real attack path (e.g., public + vulnerable + admin role).
- **TruRisk score** — Qualys's risk-based score combining CVSS with real-world threat intelligence and asset criticality.
- **TruRisk Eliminate** — Qualys's capability to apply non-patch mitigations (configuration change, disable, isolate, compensating control) to reduce risk.
- **VMDR** — Vulnerability Management, Detection and Response; Qualys's flagship workflow (asset → detect → prioritize → respond).
