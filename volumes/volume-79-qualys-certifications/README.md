# Volume LXXIX — Qualys Certification Tracks

> The whole Qualys certification program in one volume — the free Certified Specialist paths across
> VMDR, CSAM, TruRisk, Policy/PCI Compliance, TotalAppSec, Container Security, TotalCloud, EDR, and
> automation (QFlow/CAR/QQL) — on the Qualys Cloud Platform, with hands-on, defensive labs, verified
> against qualys.com.

## Overview

Volume LXXIX maps the **Qualys** certification program — the credentials for operating Qualys's
cloud-based **vulnerability management, compliance, and exposure management** platform. Qualys pioneered
SaaS security: everything runs on the **Qualys Cloud Platform** with lightweight **sensors** (Cloud
Agents, scanner appliances, passive sensors, cloud connectors, API). Its **Qualys Certified
Specialist** program is **free** and organized into paths — the flagship **VMDR (Vulnerability
Management, Detection and Response)**, plus CSAM, Enterprise TruRisk, Policy/PCI Compliance, EDR,
TotalCloud, TotalAppSec, Container Security, and automation. It joins the encyclopedia's security
volumes (Tenable LXXVIII, CrowdStrike L, GIAC LXXIV, Gigamon XVIII, Enterprise Cybersecurity X), and
completes the security certification-tracks batch.

This is a **certification-tracks** volume, like the other vendor volumes (XXXIX–LXXVIII): it maps the
program — the paths and products — and teaches each with a hands-on walkthrough. Every path and product
area was **verified against qualys.com on 28 July 2026**.

Chapters follow the platform:

- **Chapter 01** frames the program — the free Certified Specialist paths, the Cloud Platform, and VMDR.
- **Chapter 02** takes the **Qualys Cloud Platform and sensors** (Cloud Agents, QQL).
- **Chapters 03–05** take **VMDR**: asset management (CSAM); detection and TruRisk prioritization; response (Patch Management, TruRisk Eliminate).
- **Chapter 06** takes **Policy Compliance and PCI**.
- **Chapter 07** takes **Web Application and Container Security** (TotalAppSec, FIM).
- **Chapter 08** takes **TotalCloud and EDR**.
- **Chapter 09** takes **automation** (QFlow, CAR, QQL/API), currency, and career.

Every chapter follows the standard structure defined in
[templates/chapter.md](../../templates/chapter.md) and enforced by
[EDITORIAL_STANDARDS.md](../../EDITORIAL_STANDARDS.md), including per-topic hands-on labs and
knowledge checks.

> **Scope.** Vulnerability, compliance, and exposure management is a defensive discipline. Every lab
> is **authorized administration** — scanning, assessing compliance, prioritizing, and remediating on
> systems you are authorized to assess — never an attack. Scan only assets you own or are authorized
> to scan.
