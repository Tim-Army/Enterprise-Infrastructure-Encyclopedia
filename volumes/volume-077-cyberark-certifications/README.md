# Volume LXXVII — CyberArk Certification Tracks

> The whole CyberArk certification program in one volume — the Trustee → Defender → Sentry → Guardian
> progression across Privileged Access Management, EPM, Secrets Manager, Identity, and Secure Cloud
> Access — with hands-on, defensive labs, verified against cyberark.com.

## Overview

Volume LXXVII maps the **CyberArk** certification program — the credentials for deploying and
operating CyberArk's **Privileged Access Management (PAM)** and **Identity Security** platform, which
protects the privileged accounts and secrets attackers seek most. The program follows a progression:
**Trustee → Defender → Sentry → Guardian**, delivered by **Pearson VUE**, spanning **PAM Self-Hosted**
(Vault/CPM/PVWA/PSM/PTA), **Privilege Cloud**, **Endpoint Privilege Manager (EPM)**, **Secrets
Manager** (Conjur), **Identity**, and **Secure Cloud Access**. It joins the encyclopedia's security
and identity volumes (Okta LXXVI, ISC2 XL, Palo Alto XVI/LXV, Zscaler XXXV, Enterprise Cybersecurity
X).

This is a **certification-tracks** volume, like the other vendor volumes (XXXIX–LXXVI): it maps the
program — the progression and products — and teaches each with a hands-on walkthrough. Every level and
product area was **verified against cyberark.com on 28 July 2026**.

> **Currency note.** As of 2026, CyberArk operates as **part of Palo Alto Networks** and the platform
> is progressively rebranding toward **"Idira."** The component architecture (Vault, CPM, PVWA, PSM)
> and the **Defender/Sentry/Guardian** credential names are **unchanged** — verify current exam names
> and delivery on cyberark.com.

Chapters follow the progression:

- **Chapter 01** frames the program — the progression, the platform, and the Pearson VUE model.
- **Chapter 02** takes the **Trustee** foundations and platform components.
- **Chapters 03–04** take the **Defender**: Vault/account management, then session management and threat detection.
- **Chapter 05** takes the **Sentry**: deployment and architecture.
- **Chapter 06** takes **Privilege Cloud and Endpoint Privilege Manager**.
- **Chapter 07** takes **Secrets Manager** (Conjur, Credential Providers).
- **Chapter 08** takes **Identity and Secure Cloud Access** (JIT/ZSP).
- **Chapter 09** takes the **Guardian**, plus currency and career.

Every chapter follows the standard structure defined in
[templates/chapter.md](../../templates/chapter.md) and enforced by
[EDITORIAL_STANDARDS.md](../../EDITORIAL_STANDARDS.md), including per-topic hands-on labs and
knowledge checks.

> **Scope.** Privileged Access Management is a defensive discipline. Every lab is **authorized
> administration** — securing, rotating, isolating, monitoring, and governing privileged access —
> never an attack on a credential store.
