# Volume CXXVII — Glossary

| Term | Definition |
|:---|:---|
| **App instance** | A specific tenant/account of a SaaS app; Netskope CASB distinguishes corporate from personal instances of the same app for per-instance policy. |
| **CASB** | Cloud Access Security Broker — visibility and control over SaaS usage, with app-instance and activity-level granularity. |
| **Cloud Confidence Index (CCI)** | Netskope's risk rating of a cloud app, used to triage Shadow IT. |
| **CSPM / SSPM** | Cloud Security Posture Management (cloud infrastructure config) and SaaS Security Posture Management (SaaS config) — finding misconfigurations, not inspecting traffic. |
| **DLP** | Data Loss Prevention — detecting and controlling sensitive data via regex/data-identifiers, dictionaries, Exact Data Match, fingerprinting, and ML, then blocking/alerting/coaching. |
| **Exact Data Match (EDM)** | DLP that matches against a fingerprinted index of your actual records, giving near-zero false positives for regulated data. |
| **Inline (real-time) protection** | Inspecting traffic as it passes through Netskope, enabling real-time blocking; contrast with API protection. |
| **API-enabled protection** | Out-of-band scanning of data already in sanctioned SaaS via vendor APIs — retroactive, not real-time. |
| **NCCSA** | Netskope Certified Cloud Security Administrator (exam NSK101) — configure, monitor, and troubleshoot the platform; valid 2 years. |
| **NCCSI** | Netskope Certified Cloud Security Integrator — integrate Netskope into the enterprise (SAML/SSO, API, IaaS/SSPM, advanced DLP, analytics). |
| **NewEdge** | Netskope's private security cloud/network — the distributed edge that steered traffic reaches for low-latency inspection. |
| **Netskope One** | Netskope's converged SASE platform (formerly Netskope Security Cloud); the courses are Netskope One Administrator and Professional. |
| **SASE** | Secure Access Service Edge — the cloud-delivered convergence of networking (SD-WAN) and security (SSE) at the edge. |
| **SASE Accreditation** | Netskope's free, vendor-agnostic SASE-architecture course and 45-minute (80%-pass) exam; yields a certificate and LinkedIn badge. |
| **SSE** | Security Service Edge — the security half of SASE: CASB + SWG + ZTNA, plus DLP, cloud firewall, and threat protection. |
| **Skope IT** | Netskope's activity/alert/event view for visibility and troubleshooting. |
| **Steering** | Directing traffic to Netskope for inspection — via the Netskope Client, explicit/reverse proxy, IPsec/GRE tunnel, or API; coverage depends on it. |
| **SWG** | Secure Web Gateway — web filtering (URL categories, allow/block/coach), SSL/TLS inspection, and inline threat protection. |
| **ZTNA** | Zero Trust Network Access — identity- and posture-based access to specific private apps (broker + outbound-only publisher, no inbound ports), replacing network-level VPN. |
