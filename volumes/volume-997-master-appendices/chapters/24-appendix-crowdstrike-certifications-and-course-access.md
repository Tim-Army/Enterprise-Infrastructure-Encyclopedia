# Chapter 24: Appendix — CrowdStrike Certifications and Course Access

The **CrowdStrike Falcon** certification program — the seven role-based credentials
across endpoint, Next-Gen SIEM, identity, and cloud — organized by group, with each
credential's focus, exam-guide domains, and the training and delivery model. The
lineup was verified on **27 July 2026** from
**crowdstrike.com/crowdstrike-university** — the same source that anchors
[Volume L — CrowdStrike Certification Tracks](../../volume-50-crowdstrike-certifications/README.md).
Third-party exam-dump sites were excluded as sources.

**How access works at CrowdStrike.** Training is delivered through **CrowdStrike
University (CSU)** — role-based learning paths (self-paced and instructor-led) — with
free **exam guides** on each certification page. Exams are delivered through **Pearson
VUE** (a voucher is purchased per attempt), and practice happens in a licensed Falcon
tenant.

> **Currency.** CrowdStrike revises exam guides as the platform evolves — the current
> set is dated January–July 2026. The **Next-Gen SIEM** pair (CCSA/CCSE) and the
> **specialist** exams (CCIS Identity, CCCS Cloud) reflect Falcon's expansion beyond
> endpoint. Confirm the current guide (and its revision date) on crowdstrike.com
> before registering.

## Free resources and entry points

- **[CrowdStrike Falcon Certification Program](https://www.crowdstrike.com/en-us/crowdstrike-university/crowdstrike-falcon-certification-program/)** —
  the authoritative catalog and per-exam guides
- **CrowdStrike University (CSU)** — role-based learning paths (LP-A/LP-R/LP-H, SIEM,
  Identity, Cloud)
- **Exam guides** — free PDFs listing the knowledge domains for each credential

## Fees, delivery, and renewal

- **Fees (confirm at registration):** each exam requires a purchased **voucher**;
  pricing is per exam.
- **Delivery:** **Pearson VUE**. Every exam is **90 minutes / 60 questions**. The
  guides list **knowledge domains** but **no percentage weights** — prepare evenly.
- **Retakes:** a **48-hour** wait after a failed attempt; passed exams cannot be
  retaken (except version changes).
- **Validity and renewal:** all certifications are valid **three years** and renewed
  by **passing the current version of the exam** on expiry — no continuing-education
  model.

## Exam-guide domains

- **CCFA:** User Management; Sensor Deployment; Host Management and Setup; Group
  Creation; Policy Application; Rules Configuration; Dashboards and Reports;
  Workflows.
- **CCFR:** ATT&CK Frameworks; Detection Analysis; Event Search; Event Investigation;
  Search Tools; Real Time Response (RTR).
- **CCFH:** ATT&CK Frameworks; Detection Analysis; Search and Investigation Tools;
  Event Search; Reports and References; Hunting Analytics; Hunting Methodology.
- **CCSA:** Querying and Analytics; Detection Logic and Alert Analysis; Incident
  Investigation; Reporting and Communication.
- **CCSE:** User Management; Data Ingestion; Parsing; Content Creation; Automation and
  Integration.
- **CCIS:** Zero Trust Architecture; Identity Protection Tenets; Fundamentals; Domain
  Security Assessment; Risk Assessment; User Assessment; Threat Hunting and
  Investigation; Risk Management with Policy Rules; Configuration and Connectors; MFA
  and IDaaS; Falcon Fusion SOAR; GraphQL API.
- **CCCS:** Falcon Cloud Security Features and Services; Cloud Account Registration;
  Cloud Security Policies and Rules; Pre-Runtime Protection; Runtime Protection;
  Findings and Detection Analysis; Remediating and Reporting Issues.

## Notes

- **No published domain weights.** The guides define domains but not percentages —
  prepare evenly across all of them.
- **Exam guides are the study scope.** Download the current per-exam guide and check
  the revision date; the program adds specialist exams over time.
- **Defensive by design.** Falcon is EDR/XDR/SIEM/identity/cloud defense — all
  practice is authorized administration, detection, hunting, and response.
- **Renew by exam** within the three-year window.
- **Related practice** in the encyclopedia: cybersecurity in **Volume X**, Zscaler in
  **Volume XXXV**, Splunk in **Volume XLV**, and the cloud volumes where Falcon Cloud
  Security operates.
