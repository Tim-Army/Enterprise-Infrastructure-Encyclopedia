# Chapter 55: Appendix — Docker Certifications and Course Access

The **Docker** certification program — the credential for building, running, and operating containers
with Docker — organized by the exam, its domains, and the training model. The program was verified on
**29 July 2026** from **Mirantis training** (training.mirantis.com), which oversees the Docker
certification program — the same source that anchors
[Volume XCII — Docker Certification Tracks](../../volume-92-docker-certifications/README.md).
Third-party exam-dump sites were excluded as sources.

**How access works.** The **Docker Certified Associate (DCA)** is administered by **Mirantis**, which
acquired the Docker Enterprise Platform business in November 2019. Register through **Mirantis training**;
the exam is **$199 USD / €200** for one attempt (cancel or reschedule up to 48 hours before) and consists
of **13 multiple-choice and 42 discrete-option multiple-choice (DOMC) questions in 90 minutes**. In DOMC,
statements are presented one at a time for a **Yes/No** answer with no going back. The credential is
**valid for two years**. Mirantis recommends **6–12 months** of Docker experience and offers courses and
a **bootcamp**; hands-on practice uses the **free Docker Engine** (the CLI is what the exam tests).

> **Currency.** The DCA remains active under Mirantis and spans six weighted domains — Orchestration
> (~25%), Image Creation/Management/Registry (~20%), Installation and Configuration (~15%), Networking
> (~15%), Security (~15%), and Storage and Volumes (~10%). Confirm current details on
> training.mirantis.com.

  — purchase the exam
- **Free Docker Engine** — install locally for hands-on practice (the CLI the exam tests)
- **Mirantis DCA bootcamp and courses** — instructor-led preparation

## Fees, delivery, and renewal

- **Fees:** the exam is **$199 USD / €200** (one attempt); Docker Engine practice is **free**. Confirm
  current pricing on training.mirantis.com.
- **Delivery:** online; **13 multiple-choice + 42 DOMC questions**; **90 minutes**.
- **Prerequisites:** none formal; 6–12 months of Docker experience recommended.
- **Validity and renewal:** **two years**; re-certify against the current exam.

## Notes

- **Free Docker Engine.** Hands-on CLI practice — what the exam rewards — costs nothing.
- **Weight your study.** Orchestration and images are the heaviest domains.
- **DOMC format.** Rehearse decisive Yes/No answering with no going back.
- **Defensive framing.** The Security domain — scanning, content trust, secrets, rootless, and least
  privilege — hardens your own containers.
