# Chapter 12: Appendix — Microsoft Certifications Beyond Azure and Course Access

Microsoft's role-based certification program **outside Azure**, organized by
family and tier, with each credential's exam code, fee band, and the free
training that prepares it. Azure itself is catalogued separately in
[Chapter 09](09-appendix-microsoft-azure-certifications-and-course-access.md);
this appendix covers **Microsoft 365, Security (SC), Power Platform (PL),
Dynamics 365 (MB), Data and Analytics (DP), AI, and GitHub (GH)**. The lineup
and exam codes were harvested on **26 July 2026** from the **Microsoft Learn
Catalog API** and the **individual certification pages** — the same harvest
that anchors
[Volume XXXVIII — Microsoft Certifications Beyond Azure](../../volume-038-microsoft-certifications-beyond-azure/README.md).
Third-party exam-dump sites were excluded as sources.

**How access works at Microsoft.** Training is delivered free through
**Microsoft Learn** ([learn.microsoft.com](https://learn.microsoft.com)) —
self-paced learning paths, documentation, and, for most exams, a **free
practice assessment**. Exams are delivered through **Pearson VUE** (test
center or **OnVUE** online-proctored) and earn a **Credly** digital badge.
Instructor-led training is available through Microsoft Learning Partners but
is optional — the free Microsoft Learn content is the primary path.

> **Currency.** Microsoft **renames and retires exams frequently**, so the
> exam code is the currency signal — confirm each certification's code, name,
> and status on Microsoft Learn before registering. Recent examples in this
> appendix: **SC-401** replaced SC-400, **DP-700** (Fabric) replaced DP-203,
> **AI-901** replaced AI-900, and **SC-500** and **GH-600** are new. The
> authoritative enumeration is the **Catalog API**
> (`learn.microsoft.com/api/catalog?type=certifications`), not the
> JavaScript-rendered browse page.

## Free training and entry points

- **[Microsoft Learn](https://learn.microsoft.com/credentials)** — free
  self-paced learning paths and the certification catalog
- **Free practice assessments** — on most certification pages, to measure
  readiness before registering
- **[Microsoft Learn Catalog API](https://learn.microsoft.com/api/catalog)** —
  the authoritative JSON enumeration of every credential and exam
- **[GitHub Skills](https://skills.github.com)** — free interactive courses
  for the GitHub credentials
- **Microsoft Learning Partners** — optional paid instructor-led training

## Fees, delivery, and renewal

- **Fee band (US pricing; varies by country — confirm at registration):**
  **Fundamentals** exams are typically **~US$99**; **Associate, Expert, and
  Specialty** exams are typically **~US$165**. GitHub exam pricing is set per
  exam — confirm on the exam page.
- **Delivery:** **Pearson VUE**, in a test center or **online-proctored with
  OnVUE**. Most role-based exams are multiple-choice with case studies.
- **Credential:** a **Credly** digital badge plus a certificate.
- **Validity and renewal:** role-based certifications are valid for **one
  year** and renew through a **free, unproctored online assessment** on
  Microsoft Learn, available in the **six months before expiry** — no re-exam,
  no fee. Confirm the Fundamentals expiry policy on each credential's page.

## Notes

- **Exam codes are the currency signal.** Microsoft renumbers on re-scope, so
  a changed code usually means a changed blueprint. Recent changes captured
  here: **SC-400 → SC-401**, **DP-203 → DP-700**, **AI-900 → AI-901**, plus new
  **SC-500** and **GH-600**.
- **Fees are US pricing and approximate** (~$99 Fundamentals, ~$165 role-based)
  and vary by country and tax — confirm at Pearson VUE registration.
- **Renewal is free and annual** through Microsoft Learn's online assessment
  in the six months before expiry — the same low-cost-to-hold model as the
  Azure program (Chapter 09).
- **The AI and agent family changes fastest.** Several credentials are beta or
  assessment-based; re-verify against the Catalog API on a cadence.
- **Azure is separate** — see [Chapter 09](09-appendix-microsoft-azure-certifications-and-course-access.md);
  hands-on practice for the beyond-Azure credentials lives in Volumes XXXVI
  (Windows Server/AD) and XXXVII (Microsoft 365).
