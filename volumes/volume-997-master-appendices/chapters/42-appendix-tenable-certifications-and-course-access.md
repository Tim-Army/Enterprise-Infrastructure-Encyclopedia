# Chapter 42: Appendix — Tenable Certifications and Course Access

The **Tenable** certification program — the credentials for operating Tenable's vulnerability- and
exposure-management platform — organized by product certification, with the two-part exam model, the
platform products, and the delivery and renewal model. The program was verified on **28 July 2026**
from **tenable.com** — the same source that anchors
[Volume LXXVIII — Tenable Certification Tracks](../../volume-78-tenable-certifications/README.md).
Third-party exam-dump sites were excluded as sources.

**How access works.** Tenable delivers training through **Tenable University** and instructor-led
courses, paired with the product certifications. Exams are **two parts** — a **written** exam and a
hands-on **practical** exam — delivered **online with proctoring** (government photo ID required; the
practical permits access to the pyTenable/developer API documentation). Hands-on practice uses **Nessus
Essentials** (free) and product trials against **authorized** lab targets. The current certifications
cover **Tenable Vulnerability Management**, **Tenable Security Center**, and **Tenable OT Security**,
under the broader **Tenable One** exposure-management platform.

> **Currency.** Tenable's platform is consolidating under **Tenable One** exposure management (unifying
> vulnerability, web, cloud, OT, and identity exposure). Confirm the current certifications, exam
> details, and product names on tenable.com before registering.

## Free and low-cost resources and entry points

- **[Tenable Certification Program](https://www.tenable.com/education/certification-program)** — the
  authoritative certifications and exam model
- **[Tenable University / Education](https://www.tenable.com/education)** — training courses and
  learning paths
- **[Nessus Essentials](https://www.tenable.com/products/nessus/nessus-essentials)** — a free scanner
  for hands-on practice (authorized targets only)
- **[docs.tenable.com](https://docs.tenable.com/)** and **[pyTenable](https://pytenable.readthedocs.io/)**
  — product and API documentation (the practical permits API docs)

## Fees, delivery, and renewal

- **Fees:** each certification requires purchasing and passing **both** the written and practical
  exams separately; confirm current pricing on tenable.com.
- **Delivery:** online, **proctored**; written (60 MCQ, 120 min, 80%) + practical (up to 30 tasks,
  240 min, 80%).
- **Prerequisites:** none formal; the associated instructor-led course is recommended.
- **Validity and renewal:** **two years**; recertify by retaking both exam parts.

## Platform areas

- **Nessus** — the scanner engine and plugin library.
- **Tenable Vulnerability Management** — cloud VM: assets, sensors (scanners/agents/connectors),
  scans, VPR/AES prioritization.
- **Tenable Security Center** — on-prem console: repositories, scan zones, RBAC, Assurance Report
  Cards.
- **Web App Scanning (WAS)** — DAST for running web applications.
- **Tenable Cloud Security** — CSPM/CNAPP for cloud misconfigurations and toxic combinations.
- **Tenable OT Security** — passive OT/ICS visibility and exposure.
- **Tenable One** — the exposure-management platform (Cyber Exposure Score, attack paths, ASM).

## Notes

- **Two-part exams.** Every certification requires both a written and a practical exam — prepare
  hands-on.
- **Exposure management.** The platform is consolidating under Tenable One; track tenable.com.
- **Authorized targets only.** Practice with Nessus Essentials on assets you own or are authorized to
  scan.
- **Defensive scope.** Vulnerability and exposure management is defensive — the volume's labs scan,
  prioritize, and remediate authorized systems.
