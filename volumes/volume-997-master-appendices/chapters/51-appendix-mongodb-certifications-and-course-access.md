# Chapter 51: Appendix — MongoDB Certifications and Course Access

The **MongoDB** certification program — the credentials for developing on, modeling, operating, and
managing the MongoDB document database and MongoDB Atlas — organized by certification, with the exam
model, the training model, and the discount model. The program was verified on **29 July 2026** from
**mongodb.com** and **MongoDB University** (the certification-program hub and the individual exam pages)
— the same sources that anchor
[Volume LXXXVIII — MongoDB Certification Tracks](../../volume-88-mongodb-certifications/README.md).
Third-party exam-dump sites were excluded as sources.

**How access works.** MongoDB's training platform is **MongoDB University**, offering **free** on-demand
courses grouped into **Learning Paths** per role, plus practice questions, study guides, and live
instructor-led training. Exams are delivered **online-proctored** through **ProctorU**, are multiple
choice, and run in monthly exam periods; passing earns a **Credly** digital badge and a listing in the
Credly Talent Directory. Hands-on practice uses a **free** MongoDB instance — Community Edition locally or
via Docker, or a **free Atlas M0** cluster. Completing a **Learning Path earns 50% off** the exam, and
**students and educators can earn a free exam** through the student and educator programs.

> **Currency.** The program has four **Associate** certifications (Developer, Data Modeler, Atlas
> Administrator, and Database Administrator). Exam objectives track the current MongoDB major version, so
> re-study when a new version refreshes them, and confirm the catalog on mongodb.com.

## Free and low-cost resources and entry points

- **[MongoDB Certification Program](https://learn.mongodb.com/pages/certification-program)** — the
  authoritative certifications and exam pages
- **[MongoDB University](https://learn.mongodb.com/)** — **free** on-demand courses and Learning Paths
- **Free practice environment** — MongoDB Community Edition (local/Docker) or a **free Atlas M0** cluster
- **Exam study guides and practice questions** — per-exam objectives and exam-grade sample questions
- **Student and Educator programs** — a **free** exam on completing a Learning Path

## Fees, delivery, and renewal

- **Fees:** exams are **$150 USD** each; completing a Learning Path earns **50% off**; students/educators
  can earn a **free** exam. Training on MongoDB University is **free**. Confirm current pricing on
  mongodb.com.
- **Delivery:** **online-proctored via ProctorU**; multiple choice (Developer 53 questions/75 minutes;
  DBA 75 questions/90 minutes).
- **Prerequisites:** **none** for the Associate exams.
- **Validity and renewal:** re-certify against the current major version as exam objectives are refreshed.

## The certifications

Verified against mongodb.com on 29 July 2026.

| Certification | Focus |
| --- | --- |
| Associate Developer | Building applications with MongoDB and a driver (53 Q / 75 min / $150) |
| Associate Data Modeler | Document schema design and data modeling |
| Associate Database Administrator | Building, supporting, and securing self-managed MongoDB (75 Q / 90 min / $150) |
| Associate Atlas Administrator | Designing, operating, and managing MongoDB Atlas deployments |

## Notes

- **Free University + Learning Paths.** All preparation is available at no cost, and a completed path
  earns a 50% exam discount (free for students/educators).
- **Free practice.** Community Edition and Atlas M0 give a real environment at no cost.
- **Document model first.** The document model, CRUD, and aggregation ground all four Associate tracks.
- **Defensive framing.** Database security (authentication, RBAC, TLS, encryption, network isolation)
  protects your own data.
- **Related coverage** in the encyclopedia: the cloud providers (AWS **XVII**, Azure **XXXIII**, GCP
  **XXXIV**) that host Atlas, and Oracle (**XLVII**) for adjacent database-certification skills.
