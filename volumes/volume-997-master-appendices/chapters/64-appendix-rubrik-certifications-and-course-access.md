# Chapter 64: Appendix — Rubrik Certifications and Course Access

The **Rubrik** certification program — the active certification, learning paths, and access model.
Verified on **4 August 2026** from **training.rubrik.com** (Rubrik University), the source that anchors
[Volume CXXX — Rubrik Certification Tracks](../../volume-130-rubrik-certifications/README.md).
Third-party exam-dump sites were excluded as sources.

**How access works.** Rubrik's program is focused on **one active certification, RCSA (Rubrik Certified
System Administrator)**, earned through **Rubrik University** (training.rubrik.com). Two study routes: a
**free** self-paced learning path (eLearning courses + practice exams with **unlimited attempts** and
immediate feedback → final exam) or a **paid** hands-on **4-day Rubrik Security Cloud Administration
bootcamp** (~60% labs; exam questions drawn from bootcamp lecture and lab content). Badges issue on
**Credly**. **Rubrik Support credentials are required** to access Rubrik University (customer/partner
gated). Beyond RCSA, Rubrik University offers topic **workshops** (Threat Detection & Incident Recovery;
Protecting Cloud-Native Workloads; Protecting Database Workloads) — training, not separate
certifications.

> **Currency.** The older **RCE (Rubrik Certified Engineer) is retired** (expired on Credly). Rubrik
> Security Cloud evolves quickly — DSPM and identity resilience are recent additions — and the RCSA
> exam follows; re-verify the current certification list and platform capabilities on
> training.rubrik.com before planning.

## Free and low-cost resources and entry points

- **[Rubrik University](https://training.rubrik.com/)** — the authoritative training/certification hub
  (Rubrik Support credentials required to log in)
- **Free RCSA learning path** — self-paced eLearning + unlimited practice exams (on Rubrik University)
- **[Rubrik products / Cyber Resilience Platform](https://www.rubrik.com/products)** — the platform this
  program certifies
- **Free study lab:** any Linux host with `python3` models immutability/WORM, backup-delta anomaly
  detection, data classification, recovery orchestration, and RBAC (see the volume's labs)

## Fees, delivery, and renewal

- **Fees:** the **RCSA free learning path** is free; the **paid bootcamp** is purchased (contact a
  Rubrik account representative) — confirm current pricing. Lab practice is free.
- **Delivery:** self-paced eLearning + online practice exams (free path); virtual instructor-led,
  hands-on bootcamp (paid). Practice exams have unlimited attempts; readiness is signaled by
  consistently passing them. Badge via Credly.
- **Prerequisites:** none formal for RCSA; Rubrik University access requires Rubrik Support credentials.
- **Validity/renewal:** verify the current recertification policy on training.rubrik.com; the platform's
  rapid feature evolution makes periodic re-study prudent.

## Notes

- **One active certification, deliberately focused:** RCSA validates operating the platform; the depth
  comes from the workshops and the platform's own capabilities.
- **Rubrik's angle is security, not just backup:** immutability, Data Threat Analytics, DSPM, and
  identity resilience frame backup as a security control — the distinctive positioning among
  data-protection vendors ([Veeam LXXXV](../../volume-085-veeam-certifications/README.md),
  [NetApp LXXXIV](../../volume-084-netapp-certifications/README.md)).
- **Access is gated:** Rubrik University requires Rubrik Support credentials (customer/partner), unlike
  the open free-first academies of some other vendors.
