# Volume CLVI — Glossary

| Term | Definition |
|:---|:---|
| **AD Bridge** | The BeyondTrust product that extends Active Directory authentication, single sign-on, and Group Policy to Linux, Unix, and macOS — letting non-Windows systems join the AD domain so users authenticate with their existing AD credentials (via Kerberos), consolidating scattered local accounts into one centrally-governed identity per person. |
| **Application control** | EPM's allow/deny/elevate policy: known-good apps run as standard user, approved apps that need it are elevated automatically, and unknown/forbidden apps are blocked — least privilege combined with allow-listing. |
| **BeyondTrust Certified Administrator** | BeyondTrust University's credential — one per product, issued as Credly badges, granted on completing the required Instructor-Led Training plus a 40-question exam at 75%+ (two attempts, open note, online), valid two years. |
| **Credential injection** | A Privileged Remote Access feature where the privileged credential is injected into the session directly from the vault, so the remote user (often an outside vendor) never sees or holds it — they can work on a system without ever receiving its password. |
| **Credential vaulting** | Storing privileged credentials encrypted in a vault and never exposing them to users; Password Safe retrieves or injects the credential on the user's behalf, so a credential the user never held cannot be phished or reused. |
| **Endpoint Privilege Management (EPM)** | Enforcing least privilege on endpoints/servers by removing standing local admin rights and elevating specific applications (not the user) on demand under policy; certified separately for Windows, Mac, and Linux. |
| **Entitle** | The BeyondTrust product (acquired 2024) for cloud/SaaS just-in-time access: self-service access requests routed through automated approval workflows, granting time-bounded access that auto-expires — PAM's principles extended to cloud entitlements. |
| **Just-in-time (JIT) access** | Granting privilege only when needed, for only as long as needed, then revoking it — the dynamic form of least privilege, eliminating the standing privilege that sits idle as attack surface. |
| **Least privilege** | Every identity has exactly the access it needs and no more; the north star of PAM, achieved by removing standing admin and granting access per-task. |
| **PAM (Privileged Access Management)** | The discipline of securing, controlling, and monitoring privileged access (admin/root/service accounts) — the highest-leverage defensive control, since privileged-credential abuse runs through nearly every breach. |
| **Password Safe** | BeyondTrust's privileged credential vault and session manager — vaulting, automatic rotation, check-in/check-out, and privileged session management (isolation, recording, monitoring); the credential-security core of PAM. |
| **Privileged Remote Access (PRA)** | Secure remote privileged access without a VPN: brokered, least-privilege connection to specific systems (no broad network foothold) with credential injection and session recording; the safe way to grant vendor/third-party privileged access. |
| **Privileged session management (PSM)** | Brokering a privileged session so it can be isolated (target never directly exposed to the user's machine), recorded (full audit trail), and monitored live (terminable) — turning privileged access into a controlled, accountable activity. |
| **Remote Support** | BeyondTrust's secure remote-support product (the Bomgar heritage) — attended and unattended remote control through a hardened channel, with granular permissions, session recording, and user consent; a security control versus exposed RDP or consumer tools. |
| **Rotation** | Automatically changing privileged passwords on a schedule and after each use (with check-in/check-out), so a stolen credential's useful lifetime is near zero and static shared passwords are eliminated. |
| **Standing privilege** | Always-on privileged access (standing admin rights, shared static passwords, never-revoked roles) that sits idle most of the time as pure attack surface; eliminating it via least privilege and JIT is the PAM endgame. |
