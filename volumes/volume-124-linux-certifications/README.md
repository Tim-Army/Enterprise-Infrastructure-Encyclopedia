# Volume CXXIV — Linux Foundation and LPI Certification Tracks

> The two **vendor-neutral Linux** certification programs in one volume, verified 3 August 2026. **LPI
> (Linux Professional Institute)** — the Essentials tier (Linux 010, Security 020, Web Development 030,
> Open Source 050, lifetime validity) under the professional ladder **LPIC-1** (101-500 + 102-500, v5.0)
> → **LPIC-2** (201-450 + 202-450, v4.5, requires active LPIC-1) → the four **LPIC-3** specialties (300
> Mixed Environments, 303 Security, 305 Virtualization and Containerization, 306 High Availability and
> Storage Clusters, each requiring active LPIC-2), plus the **Open Technology** track (701 DevOps Tools
> Engineer, 702 BSD Specialist) — professional certs valid five years. **Linux Foundation** — the
> multiple-choice **LFCA** (Certified IT Associate) and the **performance-based LFCS** (Certified System
> Administrator: five weighted domains — Operations Deployment 25%, Networking 25%, Storage 20%,
> Essential Commands 20%, Users and Groups 10% — two-year validity); **LFCT is inactive**. Because both
> programs test only free, standard Linux, **every lab in this volume is runnable** on any Linux machine
> — the exam practice is the book. LPI's per-objective public weights and the LFCS domain weights drive
> a lab per topic/domain (66 total).

## Overview

Volume CXXIV is a **certification-tracks volume** pairing the two vendor-neutral Linux programs because
candidates routinely mix them: LPI's knowledge-tested, weighted-objective ladder and the Linux
Foundation's performance-based LFCS answer the same "prove you know Linux" question two ways — explaining
versus doing. The volume maps both, exam by exam, with a walkthrough lab per LPI top-level topic and per
LFCS domain, all runnable free.

Its standing disciplines are the two renewal cadences (LPIC 5-year with active-cert chaining, LFCS
2-year, Essentials lifetime), objective-version awareness (101/102-500 v5.0; 201/202-450 v4.5), and the
LFCT-inactive lesson: verify a certification against the vendor's status, not course availability.

## What you will be able to do

- Map both vendor-neutral Linux programs and choose or stack certifications by role.
- Work every LPIC-1/2 topic and LPIC-3 specialty from the published weighted objectives.
- Drill the LFCS's five domains in performance-exam style, with verification habits.
- Cover the Open Technology track (DevOps Tools Engineer, BSD Specialist).
- Keep certifications current across two renewal cadences and the active-cert chaining rule.
