# Volume CXXIV — Glossary

| Term | Definition |
|:---|:---|
| **Active-cert chaining** | LPI's rule that LPIC-2 requires an active LPIC-1 and LPIC-3 an active LPIC-2 — letting the base lapse invalidates the higher certification's prerequisite. |
| **BSD Specialist (702)** | LPI Open Technology certification covering the BSD family (FreeBSD/OpenBSD/NetBSD) — Unix skills applied off Linux (pkg/ports, rc.conf, pf, ZFS). |
| **DevOps Tools Engineer (701)** | LPI Open Technology certification: vendor-neutral DevOps literacy — IaC, config management, containers, CI/CD, monitoring, and idempotence. |
| **Essentials** | LPI's entry credentials (Linux 010, Security 020, Web Development 030, Open Source 050): 40 questions, 60 minutes, no prerequisites, **lifetime** validity. |
| **FHS** | Filesystem Hierarchy Standard — the standardized meaning of `/etc`, `/var`, `/usr`, `/home`, etc., tested in LPIC-1 Topic 104. |
| **LFCA** | Linux Foundation Certified IT Associate — a 60-question multiple-choice pre-professional credential spanning Linux, sysadmin, cloud, security, and DevOps basics. |
| **LFCS** | Linux Foundation Certified System Administrator — a two-hour **performance-based** exam (real terminal tasks) across five weighted domains; two-year validity. |
| **LFCT** | Linux Foundation Certified Cloud Technician — **inactive/discontinued**; its LFS203 course still sells, which is why course availability is not proof a certification lives. |
| **LPI** | Linux Professional Institute — the vendor-neutral Linux certification body; every exam publishes detailed public objectives with per-objective weights. |
| **LPIC-1 / -2 / -3** | LPI's professional ladder: LPIC-1 (two exams, junior admin), LPIC-2 (two exams, senior admin, needs active LPIC-1), LPIC-3 (four single-exam specialties, needs active LPIC-2). |
| **Objective version** | The revision of an exam's published objectives (101/102-500 are v5.0; 201/202-450 are v4.5) — study the current version, not a book's snapshot. |
| **Performance-based exam** | An exam scored on completing real tasks in a live environment (LFCS), as opposed to multiple choice; unverified work is unscored. |
| **Per-objective weight** | The 1–5 weight LPI assigns each objective, indicating how many questions it draws — the map for where study hours go. |
| **Quorum** | The majority-of-votes a cluster needs to run; why clusters use odd node counts and stop rather than split-brain (LPIC-3 306). |
| **STONITH / fencing** | "Shoot The Other Node In The Head" — cluster fencing that isolates a failed node so it cannot corrupt shared state (LPIC-3 306). |
| **THRIVE / killer.sh** | The exam-simulator environment bundled with LFCS registration for timed practice. |
