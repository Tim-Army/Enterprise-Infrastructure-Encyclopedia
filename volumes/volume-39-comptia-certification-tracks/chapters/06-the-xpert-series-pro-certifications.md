# Chapter 06: The Xpert Series — Pro Certifications

## Learning Objectives

- Explain what the CompTIA Xpert Series ("Pro" credentials) is and how it differs from the classic exams.
- Enumerate the current Pro credentials and their focus areas.
- Describe CloudNetX and the Hybrid Server Pro sequence.
- Recognize the new AI and OT security certifications, SecAI+ and SecOT+.
- Decide when a hands-on "Pro" credential fits a role better than a classic "plus" exam.

## Theory and Architecture

The **Xpert Series** is CompTIA's newer, hands-on line, introduced as part of
the program's 2024–2025 relaunch. Where the classic "plus" exams validate
**knowledge and scenario judgment**, the Xpert line emphasizes **demonstrated
ability in realistic, lab-style environments**. It is important to see that this newer,
hands-on material spans **three different kinds** of offering:

- **Xpert Series certifications** — advanced/expert, exam-coded, **pass/fail**
  certifications: **CloudNetX (CNX-001)** and **DataAI (DY0-001)**.
- **Expansion Series certifications** — CompTIA's newer AI- and
  operational-technology security certifications: **SecAI+ (CY0-001)** and
  **SecOT+ (SOT-001)**. These are **scaled-score** exams (SecAI+ passes at 600
  on a 100–900 scale).
- **"Pro" training courses with a competency assessment** — CertMaster learning
  products (**Hybrid Server Pro**, **CyberDefense Pro**, **Ethical Hacker Pro**,
  **Linux Pro**, and **Security Pro**) that build and validate hands-on skills
  and **ladder toward** a CompTIA or vendor certification rather than being a
  standalone CompTIA exam. The "Pro" naming spans both the competency assessment
  and its preparatory course.

(The chapter file is named for the Xpert Series, but for completeness it also
covers the Expansion Series certifications and the "Pro" courses.) As verified
on comptia.org (26 July 2026), these offerings include:

- **CompTIA CloudNetX** — exam **CNX-001** (V1, launched 18 February 2025). An
  **expert-level** credential spanning **cloud and network architecture**
  together — designing, securing, monitoring, and troubleshooting connectivity
  across hybrid environments, including hands-on Zero Trust implementation. It
  is a **pass/fail** exam of up to **90 questions** (multiple-choice and
  performance-based) over **165 minutes**, in English, with a steep recommended
  background (**~10 years IT, 5 as a network architect**, plus foundational
  knowledge equivalent to **Network+, Security+, and Cloud+**). Its four
  weighted domains are **Network architecture design (31%)**, **Network security
  (28%)**, **Network troubleshooting (25%)**, and **Network operations,
  monitoring, and performance (16%)** — covering topologies and hybrid
  connectivity (VPN, SD-WAN, MPLS, cloud interconnect), Zero Trust/SASE/ZTNA and
  IAM, IaC-driven operations and monitoring, and connectivity/performance/
  security troubleshooting. CloudNetX is the flagship of the Xpert Series.
- **CompTIA Hybrid Server Pro** — a two-part sequence, **Hybrid Server Pro I:
  Core** and **Hybrid Server Pro II: Advanced**. Unlike CloudNetX and DataAI,
  these are **CertMaster training courses paired with a competency assessment**
  rather than exam-coded certifications. **Core** builds foundational hybrid
  server-administration skills and **also prepares you for Microsoft's AZ-800**
  (*Administering Windows Server Hybrid Core Infrastructure*); **Advanced**
  covers advanced administration and **prepares you for Microsoft's AZ-801**
  (*Configuring Windows Server Hybrid Advanced Services*). The Advanced
  competency assessment (V1) spans **hybrid infrastructure administration**
  (admin tasks and on-premises-to-Azure migration), **securing and updating
  Windows** (Defender for Endpoint/Application Control, AD account/group/DC
  hardening, BitLocker/Azure Disk Encryption), **backup and disaster recovery**
  (Azure Recovery Services Vault, replication, site recovery), **high
  availability and failover clustering** (NLB, quorum, Storage Spaces Direct),
  and **troubleshooting Windows Servers**. The sequence therefore ladders toward
  the Microsoft Windows Server hybrid credentials (Volume XXXVI) rather than
  being a CompTIA exam of its own.
- **CompTIA CyberDefense Pro** — a hands-on **defensive-security** training
  course paired with the CyberDefense Pro **competency assessment**; it also
  **prepares you for CySA+ (V3, CS0-003)** — note the current CySA+ exam is now
  **V4 (CS0-004)**, so confirm which version the course targets on comptia.org.
- **CompTIA Ethical Hacker Pro** — a hands-on **ethical-hacking** training course
  and competency assessment (V1). Its objectives run the full offensive cycle:
  **Prepare** (reconnaissance, scanning, enumeration), **Gain Access**
  (credential attacks, privilege escalation, cracking), **Attack** (passive and
  active online attacks, infrastructure attacks), **Cover up**, and **Defend a
  System**. Its page frames it as **career preparation** rather than naming a
  specific cert to prepare for, though the offensive scope aligns closely with
  **PenTest+**.
- **CompTIA Linux Pro** — a hands-on **Linux administration** training course and
  competency assessment (V6) that **prepares you for CompTIA Linux+**. Its
  objectives cover **system administration and configuration** (command-line
  utilities, shells, startup/shutdown, processes, package management with
  RPM/DNF/apt), **storage and file-system management** (partitions, file
  systems, LVM, the Filesystem Hierarchy Standard, quotas, archives),
  **networking** (IP configuration and troubleshooting), and **security and
  access control** (users/groups, ownership and permissions, umask, logging,
  host firewall). Note the course page cites **Linux+ V5**, while the current
  Linux+ exam is **XK0-006** — confirm the intended version on comptia.org.
- **CompTIA Security Pro** — a hands-on **security** training course and
  competency assessment (V8) that **prepares you for CompTIA Security+ (V7,
  SY0-701)**. Its objectives cover **identity management and authentication**
  (Windows/Linux/AD identity, account policies, GPOs), **physical and network
  security** (firewalls, DMZ, NAT, switch/router/VPN/VLAN and wireless
  hardening, BYOD), **host and application defenses** (NTFS permissions,
  anti-virus, application whitelisting, DEP, web/email/browser hardening,
  virtualization), **data security** (backup/recovery, redundancy, encryption
  and certificates), and **audits and security assessments** (advanced audit
  policy, intrusion detection, vulnerability scanning, attack analysis).
- **CompTIA SecAI+** — exam **CY0-001** (V1, launched 17 February 2026), the
  **first certification in CompTIA's Expansion Series**. It covers securing,
  governing, and responsibly integrating AI into cybersecurity operations. It is
  a **60-question** exam (multiple-choice and performance-based) over **60
  minutes**, in English, with a **scaled passing score of 600 (on a 100–900
  scale)** and a recommended background of **3–4 years in IT, 2+ years hands-on
  security** (Security+, CySA+, or PenTest+ recommended). Its four weighted
  domains are **Basic AI concepts related to cybersecurity (17%)**, **Securing
  AI systems (40%)**, **AI-assisted security (24%)**, and **AI governance, risk,
  and compliance (19%)** — spanning AI/ML fundamentals and AI-driven threats,
  protecting AI systems/models/pipelines against adversarial attack, using AI to
  accelerate detection and response, and GRC frameworks such as GDPR and the
  NIST AI RMF.
- **CompTIA SecOT+** — exam **SOT-001** (V1), a new **operational-technology
  (OT) security** certification for critical-infrastructure and manufacturing
  environments, **launching December 2026** (the second security certification
  in the Expansion Series alongside SecAI+). It is multiple-choice and
  performance-based; question count, length, and passing score are **TBD**, and
  the objectives are currently a **published draft (v1.2)**. Recommended
  experience is **3+ years in OT and 2+ years in OT cybersecurity**. Its six
  weighted domains are **OT Systems and Safety Foundations (14%)**, **OT Risk
  Management (17%)**, **OT Threat Intelligence (14%)**, **OT Cybersecurity
  Architecture, Design, and Engineering (18%)**, **OT Security Operations
  (22%)**, and **OT Incident Management (15%)** — spanning ICS/SCADA safety and
  control theory, governance/risk/compliance, OT threat intelligence (OT-specific
  frameworks and historical incidents such as Stuxnet), secure OT architecture
  and engineering, asset and vulnerability management, and OT incident response
  (PICERL, ICS4ICS).
- Additional Pro credentials — **PC Pro**, **Windows Client Pro**, **Cisco
  Networking Pro**, **AutoOps**, and **Digital Literacy Pro** — round out the
  practical line.

## Design Considerations

Choose a **Pro** credential when a role needs **demonstrated hands-on ability**
rather than knowledge validation. A hiring manager who wants proof that a
candidate can actually defend a network, run a hybrid server estate, or design
secure cloud connectivity may value **CyberDefense Pro**, **Hybrid Server
Pro**, or **CloudNetX** over — or in addition to — the classic exam. The
classic "plus" certifications remain the broad, widely recognized baseline; the
Pro credentials are the **practical, specialized layer** above them.

Watch the **Expansion Series certifications**: **SecAI+ (CY0-001)** and
**SecOT+ (SOT-001)** address AI and operational-technology security — two of the
fastest-growing risk areas. **SecAI+ is already available** (launched February
2026, a 60-question/60-minute exam with a scaled 600/100–900 passing score),
while **SecOT+ launches December 2026** with its objectives currently in draft
(question count, length, and passing score TBD). Verify status and format on
comptia.org before planning around a brand-new certification. **CloudNetX
(CNX-001)** remains the Xpert flagship, uniting the cloud and network expertise
that modern infrastructure roles demand.

## Implementation and Automation

Verify the Pro credentials and CloudNetX from comptia.org:

```bash
for slug in cloudnetx hybrid-server-pro-core hybrid-server-pro-advanced \
            cyber-defense-pro ethical-hacker-pro linux-pro security-pro secai secot; do
  title=$(curl -sSL -A "Mozilla/5.0" "https://www.comptia.org/en-us/certifications/$slug/" \
    | grep -oE '<title>[^<]*</title>' | head -1 | sed -E 's/<\/?title>//g')
  code=$(curl -sSL -A "Mozilla/5.0" "https://www.comptia.org/en-us/certifications/$slug/" \
    | grep -oE '\b(CNX-[0-9]{3}|CY0-[0-9]{3}|SOT-[0-9]{3})\b' | sort -u | tr '\n' ' ')
  echo "$slug -> ${code:-course+assessment} | $title"
done
# cloudnetx -> CNX-001 ; secai -> CY0-001 ; secot -> SOT-001 (Coming December 2026)
# The "Pro" slugs return no code — they are courses with a competency assessment.
```

## Validation and Troubleshooting

Separate the exam-coded **Xpert certifications** from the **"Pro" courses with a
competency assessment**:

| Offering | Type | Code / ladders to | Focus |
| --- | --- | --- | --- |
| CloudNetX | Xpert certification | CNX-001 | Cloud + network architecture (expert flagship) |
| DataAI (see Ch 05) | Xpert certification | DY0-001 | Advanced data science and AI |
| SecAI+ | Expansion certification | CY0-001 | AI security (GA Feb 2026) |
| SecOT+ | Expansion certification | SOT-001 | OT security (GA Dec 2026) |
| Hybrid Server Pro I: Core | Course + competency assessment | Microsoft AZ-800 | Hybrid server admin (core) |
| Hybrid Server Pro II: Advanced | Course + competency assessment | Microsoft AZ-801 | Hybrid server admin (advanced) |
| CyberDefense Pro | Course + competency assessment | prepares for CySA+ (V3) | Defensive security |
| Ethical Hacker Pro | Course + competency assessment | aligns with PenTest+ (career-focused) | Offensive security |
| Linux Pro | Course + competency assessment | prepares for Linux+ (page cites V5) | Linux administration |
| Security Pro | Course + competency assessment | prepares for Security+ (V7, SY0-701) | Security |

Common pitfalls: treating every **"Pro"** item as an exam-coded certification —
CloudNetX, DataAI, SecAI+, and SecOT+ are certifications, but **Hybrid Server
Pro** (and the CyberDefense/Ethical Hacker/Linux/Security Pro products) are
**training courses with a competency assessment** that ladder toward a CompTIA
or vendor certification (Hybrid Server Pro → Microsoft AZ-800/AZ-801); planning
around **SecOT+** before it is generally available (SOT-001 was slated for
December 2026); and forgetting that the whole line is **hands-on and
performance-based**, so preparation is lab work, not reading alone. Verify each
offering's current format and status on comptia.org — this line is new and still
expanding.

## Security and Best Practices

Use the **Pro** credentials where **demonstrated, hands-on ability** is the
requirement, layered on the classic "plus" baseline. Track the **emerging AI
and OT security** certifications (**SecAI+**, **SecOT+**) — securing AI systems
and operational technology are rapidly growing needs. Treat **CloudNetX
(CNX-001)** as the Xpert flagship worth knowing for senior infrastructure
roles. Because the Pro line is new, **verify availability, format, and codes on
comptia.org** before committing study time, and prepare with **hands-on labs**
that mirror the performance-based exam environment. Plan **CE renewal**
(Chapter 08) per each credential's stated validity.
