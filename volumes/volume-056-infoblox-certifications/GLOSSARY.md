# Volume LVI Glossary

Definitions for terms used in **Volume LVI — Infoblox Certification Tracks**,
alphabetized. See also the [volume index](INDEX.md) and the
[master glossary](../../GLOSSARY.md) for cross-volume terminology.

**Admin group** — A NIOS access-control object grouping admins with scoped roles/
permissions. Used in Chapter 03.

**DDI** — The integration of DNS, DHCP, and IP address management (IPAM). Used
throughout.

**Discovery** — NIOS network discovery that finds devices and reconciles IPAM data. Used
in Chapter 03.

**DNS forwarding proxy (DFP)** — A Threat Defense component that steers client DNS through
inspection. Used in Chapter 06.

**Grid** — The Infoblox NIOS clustered architecture: a Grid Master (and Master Candidate)
plus members. Used in Chapters 02 and 04.

**Grid Master Candidate (GMC)** — A member designated to take over if the Grid Master
fails. Used in Chapter 04.

**IMA** — NetMRI Administrator certification. Used in Chapter 07.

**INA / INE / INO** — NIOS DDI Administrator / Expert / Operator certifications. Used in
Chapters 02–04.

**IPAM** — IP Address Management; NIOS tracks networks and allocates addresses (e.g.,
next-available). Used in Chapter 02.

**NetMRI** — Infoblox's multi-vendor network change/configuration management and
automation platform. Used in Chapter 07.

**NIOS** — Infoblox's on-premises Network Identity Operating System (the Grid). Used
throughout.

**NIOS-X** — The host software delivering DNS/DHCP for Universal DDI. Used in Chapter 05.

**Threat Defense** — Infoblox's DNS-layer security service (blocking, analytics). Used in
Chapter 06.

**Threat Insight** — Threat Defense analytics detecting DNS tunneling/DGA/exfiltration.
Used in Chapter 06.

**Universal DDI** — Infoblox's cloud-native DDI managed from the Infoblox Portal over
NIOS-X hosts. Used in Chapter 05.

**WAPI** — The NIOS REST API (`/wapi/v2.x/`) for programmatic management. Used in Chapters
01–04.
