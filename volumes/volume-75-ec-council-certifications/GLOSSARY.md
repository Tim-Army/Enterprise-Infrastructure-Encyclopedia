# Volume LXXV Glossary

Definitions for terms introduced in **Volume LXXV — EC-Council Certification Tracks**.
See the [master glossary](../../GLOSSARY.md) for cross-volume terms.

- **CAIPM** — Certified AI Program Manager; governing AI initiatives with accountability and ethics.
- **CASE** — Certified Application Security Engineer (.NET and Java editions); building security into the software development lifecycle.
- **CCISO** — Certified Chief Information Security Officer; EC-Council's executive security-leadership credential across five domains.
- **CCSE** — Certified Cloud Security Engineer; securing multi-cloud environments under the shared responsibility model.
- **CCT** — Certified Cybersecurity Technician; EC-Council's broad, hands-on entry credential.
- **CEH** — Certified Ethical Hacker (current version v13, AI-integrated); authorized ethical-hacking methodology across 20 modules.
- **CEH Master** — the credential earned by passing both the CEH knowledge exam and the CEH Practical (iLabs) exam.
- **CHFI** — Computer Hacking Forensic Investigator; the digital-forensics investigation process.
- **CND** — Certified Network Defender; EC-Council's defense-in-depth blue-team credential (DoD 8140 aligned).
- **COASP** — Certified Offensive AI Security Professional; authorized AI-security assessment.
- **CPENT** — Certified Penetration Testing Professional; the rigorous, authorized penetration-testing process.
- **CRAGE** — Certified Responsible AI Governance & Ethics; ethics and governance for AI.
- **CSA** — Certified SOC Analyst; monitoring, triaging, and escalating in a security operations center.
- **CSCU** — Certified Secure Computer User; end-user security awareness.
- **CTIA** — Certified Threat Intelligence Analyst; the threat-intelligence lifecycle.
- **DoD 8140/8570** — US Department of Defense workforce baseline that CEH, CND, and CHFI satisfy.
- **ECDE** — Certified DevSecOps Engineer; embedding security into CI/CD pipelines.
- **ECE credits** — EC-Council Continuing Education credits used to maintain certifications.
- **ECES** — Certified Encryption Specialist; applied cryptography (symmetric/asymmetric, hashing, PKI).
- **ECIH** — EC-Council Certified Incident Handler; the incident-response lifecycle.
- **ECSS** — EC-Council Certified Security Specialist; a foundation across networking, security, and forensics.
- **Essentials series** — EC-Council's free-to-learn foundational courses (Network Defense, Ethical Hacking, Digital Forensics Essentials, and more).
- **iLabs Cyber Range** — EC-Council's hands-on practical-exam environment (used for CEH Practical, CPENT, LPT).
- **LPT (Master)** — Licensed Penetration Tester Master; EC-Council's elite, fully hands-on penetration-testing credential.
- **WAHS** — Web Application Hacking and Security; authorized web-application assessment methodology.
