# Volume LXVII Glossary

Definitions for terms introduced in **Volume LXVII — Nokia Certification Tracks**.
See the [master glossary](../../GLOSSARY.md) for cross-volume terms.

- **4A0-100** — the NRS I exam ("Nokia IP Networks and Services Fundamentals").
- **4A0-C03 / 4A0-C04** — the NRS II composite-written exam variants (IS-IS and OSPF respectively).
- **4A0-N01** — the NRS II 3.5-hour practical lab exam.
- **4A0-112** — the Service Routing Architect (SRA) exam.
- **Classic CLI** — SR OS's traditional command-line interface (`info`, `admin save`).
- **Epipe (VLL)** — a point-to-point Layer-2 pseudowire service on SR OS.
- **EVPN** — the BGP control plane distributing MAC/IP reachability for Layer-2/Layer-3 services.
- **IS-IS** — a link-state IGP using levels (L1/L2), favored in SP cores and SR-friendly.
- **LDP** — Label Distribution Protocol; distributes MPLS labels along the IGP shortest path.
- **MD-CLI** — SR OS's model-driven CLI, aligned to the YANG data model with candidate/commit semantics.
- **NRS I / NRS II** — Nokia Certified Network Routing Specialist I (entry) and II (professional).
- **OSPF** — a link-state IGP organized into areas around a backbone (area 0).
- **pySROS** — Nokia's official Python library for scripting SR OS against its YANG model.
- **RSVP-TE** — signals explicit, traffic-engineered MPLS LSPs with bandwidth reservation and fast reroute.
- **SAP (Service Access Point)** — the customer-facing port/VLAN of an SR OS service.
- **SDP (Service Distribution Point)** — the transport tunnel between PEs that a service binds to.
- **Segment Routing (SR-MPLS)** — source routing encoding the path as a stack of IGP-advertised segment IDs, without LDP/RSVP core state.
- **SR OS** — Nokia's Service Router Operating System (7750 SR, 7450 ESS, 7950 XRS).
- **SRA (Service Routing Architect)** — Nokia's expert design credential (exam 4A0-112).
- **SRC** — the Nokia Service Routing Certification program.
- **System interface** — the SR OS loopback used as router ID and stable protocol source.
- **VPLS** — a multipoint Layer-2 service emulating a LAN/switch across sites.
- **VPRN** — a multipoint Layer-3 VPN service (per-customer VRF, MP-BGP VPN-IPv4).
