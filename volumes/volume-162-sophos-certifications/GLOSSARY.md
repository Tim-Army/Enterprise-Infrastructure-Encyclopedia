# Volume CLXII — Glossary

| Term | Definition |
|:---|:---|
| **Adaptive Attack Protection** | An Intercept X feature that dynamically heightens a device's defenses when an active attack (hands-on-keyboard adversary) is detected, becoming more aggressive so the attacker's later moves are blocked. |
| **Architect** | The deepest Sophos Academy tier — validates deployment and design expertise (e.g., AT15 for Central Endpoint, Intercept X & Server: update caches, message relays, AD sync, segmented policy). |
| **CryptoGuard** | Intercept X's behavior-based anti-ransomware — detects the malicious mass-encryption behavior all ransomware performs, stops the process, and rolls back affected files to their pre-attack state, catching never-before-seen ransomware and reversing damage. |
| **Deep Learning** | Intercept X's neural-network AI model that detects malware by its characteristics, including never-before-seen (zero-day) threats, without needing a prior signature — predictive detection. |
| **EDR** | Endpoint Detection and Response — recording endpoint activity to detect, investigate, hunt, and respond to threats that prevention misses; extended across data sources it becomes XDR. |
| **Exploit Prevention** | An Intercept X capability that blocks the techniques attackers use to exploit vulnerabilities (buffer overflows, code injection, credential theft) regardless of the specific malware — stopping attacks by their method. |
| **Security Heartbeat** | The live link in Synchronized Security between Intercept X endpoints and the Sophos Firewall — endpoints report health (green/yellow/red), so a red (threat-detected) heartbeat lets the firewall respond. |
| **Sophos Central** | The single cloud console that manages every Sophos product (endpoint, firewall, MDR, email, wireless, ZTNA, encryption) — unified policy, alerts, reporting, and response; the platform foundation. |
| **Sophos Firewall** | Sophos's next-generation firewall (XGS hardware or virtual/cloud) — TLS inspection, IPS, web and application control, and sandboxing on the high-performance Xstream architecture. |
| **Sophos MDR** | Sophos's Managed Detection and Response — a 24/7 SOC-as-a-service where Sophos analysts monitor, hunt, investigate, and respond to threats on the customer's behalf; built on XDR. |
| **Synchronized Security** | Sophos's signature approach — products (firewall and endpoint) that share threat intelligence via the Security Heartbeat and respond as one, including automatically isolating a compromised device to stop lateral movement. |
| **Technician / Administrator / Engineer / Architect** | The four Sophos Academy role tiers — support, day-to-day administration, configuration, and deployment/design — earned per product. |
| **WipeGuard** | An Intercept X feature protecting the Master Boot Record and boot process against wiper attacks that destroy the boot record to render a machine unbootable. |
| **XDR** | Extended Detection and Response — extending detection beyond the endpoint to correlate signals across network, email, cloud, and identity into one attack story; the basis of Sophos MDR (strengthened by the Secureworks Taegis acquisition). |
| **Xstream architecture** | Sophos Firewall's packet-processing architecture designed for high-performance deep inspection, especially TLS/SSL inspection at scale without crippling throughput. |
| **Update Cache / Message Relay** | Deployment components an Architect plans — a local cache so endpoints pull updates nearby (saving bandwidth), and a relay so endpoints in segmented networks reach Sophos Central without direct internet access. |
