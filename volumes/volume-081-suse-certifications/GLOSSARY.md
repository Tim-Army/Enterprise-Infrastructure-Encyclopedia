# Volume LXXXI Glossary

Definitions for terms introduced in **Volume LXXXI — SUSE Certification Tracks**.
See the [master glossary](../../GLOSSARY.md) for cross-volume terms.

- **AppArmor** — SLES's default mandatory-access-control system, confining programs to declared file and capability access via profiles.
- **AutoYaST** — SUSE's automated-installation system, using an XML profile to perform unattended, repeatable deployments.
- **Btrfs** — the copy-on-write filesystem SLES uses for the root filesystem, enabling snapshots.
- **Content Lifecycle Management** — SUSE Manager's workflow for promoting a validated set of patches through environments (dev → test → prod).
- **Corosync** — the cluster membership and messaging layer of the SUSE HA Extension.
- **K3s** — SUSE's lightweight Kubernetes distribution for edge and IoT.
- **Longhorn** — SUSE's cloud-native, replicated block-storage system for Kubernetes persistent volumes.
- **NeuVector** — SUSE's defensive container-security platform (image scanning, admission control, learned zero-trust runtime segmentation).
- **Pacemaker** — the resource manager of the SUSE HA Extension, starting/stopping/failing over resources across cluster nodes.
- **Questionmark** — the remote, proctored assessment platform that delivers SUSE certification exams.
- **Rancher** — SUSE's Kubernetes management platform for provisioning, governing, and securing many clusters.
- **RKE2** — SUSE's security-focused, government-grade Kubernetes distribution for servers.
- **Salt** — the automation engine (states + remote execution) SUSE Manager uses to configure and command managed systems.
- **SCA (SUSE Certified Administrator)** — SUSE's administrator-level certification, per product.
- **SCDS (SUSE Certified Deployment Specialist)** — SUSE's deployment/configuration-level certification.
- **SCE (SUSE Certified Engineer)** — SUSE's advanced engineering-level certification.
- **SLE Micro** — SUSE's immutable, transactional Linux for edge and container hosts.
- **SLES (SUSE Linux Enterprise Server)** — SUSE's enterprise Linux distribution.
- **Snapper** — SLES's snapshot manager, taking automatic Btrfs snapshots before/after changes to enable rollback.
- **SUSE Manager** — SUSE's infrastructure-management platform for patching, configuring, and provisioning Linux fleets.
- **transactional-update** — the tool that applies updates atomically into a new snapshot on immutable SLE Micro hosts.
- **YaST** — SUSE's signature configuration tool (yast2) providing guided modules for administration.
- **zypper** — SLES's command-line package manager (install/remove, patches, repositories).
