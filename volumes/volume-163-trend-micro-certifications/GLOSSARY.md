# Volume CLXIII — Glossary

| Term | Definition |
|:---|:---|
| **Apex One** | Trend Micro's endpoint protection product with EDR — layered detection (signature, behavioral, machine learning, exploit protection) plus virtual patching; a standalone endpoint product and an XDR sensor. |
| **ASRM (Attack Surface Risk Management)** | A Trend Vision One pillar that proactively discovers the attack surface (including unknown/shadow-IT assets), assesses and risk-scores exposures, and prioritizes remediation — reducing risk before an attack, complementing reactive XDR. |
| **Attack story** | XDR's visual, connected narrative of an attack from root cause through every step, giving responders the full scope (entry point and all affected assets) to respond completely. |
| **Certified Professional** | Trend Micro's core technical credential, earned per product (e.g., Certified Professional for Deep Security), validating the skills to deploy and manage a solution; exams use scenario-based items. |
| **Cloud App Security** | Trend Micro's API-based email and collaboration security for Microsoft 365 and Google Workspace — detecting phishing, BEC, malicious attachments (sandboxed), and malicious URLs on top of native protection. |
| **Conformity** | Trend Micro's Cloud Security Posture Management (CSPM) — continuously checking cloud configurations against best practice and compliance benchmarks to find and fix misconfigurations before runtime. |
| **Deep Discovery** | Trend Micro's network detection and sandboxing for targeted attacks and APTs — watching network traffic for advanced-attack indicators and detonating suspicious files. |
| **Deep Security** | Trend Micro's server and workload protection (within Cloud Security / Vision One) — multiple modules (IPS/virtual patching, anti-malware, integrity monitoring, log inspection, application control, firewall) in one agent across physical, virtual, cloud, and container workloads. |
| **Smart Protection Network** | Trend Micro's global threat-intelligence backbone — correlating telemetry from hundreds of millions of sensors so a threat seen anywhere protects everyone in near real time, feeding prevention, XDR detection, and ASRM risk context. |
| **TippingPoint** | Trend Micro's network intrusion prevention system (IPS) — in-line appliances that inspect and block exploits, malware, and attacks in network traffic in real time. |
| **Trend Vision One** | Trend Micro's unified cybersecurity platform — one console combining XDR, Attack Surface Risk Management, and threat intelligence across endpoint, server, cloud, email, network, and identity. |
| **Virtual patching** | Host-based intrusion prevention that shields a vulnerability with a protective (IPS) rule before the actual vendor patch is applied — closing the exposure window immediately and protecting unpatchable (legacy/EOL) systems. |
| **XDR (Extended Detection and Response)** | The core of Vision One — extending detection beyond the endpoint to correlate telemetry across all layers (endpoint, email, network, cloud, identity) into one attack story and respond across every affected layer. |
| **Zero Trust Secure Access (ZTSA)** | Trend Micro's zero-trust access — granting per-resource access based on continuous, risk-based verification of identity, device health, and live risk signals, restricting access automatically when risk rises. |
