# Chapter 46: Appendix — Alibaba Cloud Certifications and Course Access

The **Alibaba Cloud** certification program — the credentials for building on the leading
Asia-Pacific cloud — organized by level and domain, with the exam model, the training model, and the
practice options. The program was verified on **29 July 2026** from **alibabacloud.com** and
**Alibaba Cloud Academy** — the same sources that anchor
[Volume LXXXII — Alibaba Cloud Certification Tracks](../../volume-82-alibaba-cloud-certifications/README.md).
Third-party exam-dump sites were excluded as sources.

**How access works.** Alibaba Cloud delivers training and certification through **Alibaba Cloud
Academy** (edu.alibabacloud.com) — courses and learning paths mapped to each certification — with
**online proctored** exams. Hands-on practice uses a **free-tier / trial** account (many services
offer a free tier or trial credits) and the **aliyun** CLI. The program has three levels — **ACA**
(Associate), **ACP** (Professional), and **ACE** (Expert) — across domains including Cloud Computing,
Cloud Security, Big Data, Cloud Native, Database, Networking, DevOps, and Machine Learning/AI.

> **Currency.** Cloud services evolve continuously, and certifications are typically valid **two
> years**, so renew as services and best practices change. Confirm the current exams, domains, and
> service names on alibabacloud.com before registering.

## Free and low-cost resources and entry points

- **[Alibaba Cloud Training & Certification](https://www.alibabacloud.com/en/training-and-certification)**
  — the authoritative levels, domains, and exams
- **[Alibaba Cloud Academy](https://edu.alibabacloud.com/)** — courses and learning paths
- **Alibaba Cloud free tier / trial credits** — hands-on practice
- **Alibaba Cloud documentation** — ECS, VPC, OSS, RDS, ACK, MaxCompute, and PAI
- **aliyun CLI** — scriptable, repeatable practice

## Fees, delivery, and renewal

- **Fees:** per-exam fees via Alibaba Cloud Academy; confirm current pricing on alibabacloud.com.
- **Delivery:** online, **proctored** through Alibaba Cloud Academy.
- **Prerequisites:** none strict; ACA grounds ACP and ACE.
- **Validity and renewal:** approximately **two years**; renew as services evolve.

## Notes

- **Native service names.** Learn ECS/VPC/OSS/RDS/ACK/MaxCompute/PAI — not AWS/Azure equivalents.
- **Free tier.** A trial account plus the aliyun CLI supports most hands-on preparation.
- **Two-year currency.** Renew as services and best practices evolve.
- **Defensive security.** The Cloud Security domain is defensive protection of your own tenancy.
