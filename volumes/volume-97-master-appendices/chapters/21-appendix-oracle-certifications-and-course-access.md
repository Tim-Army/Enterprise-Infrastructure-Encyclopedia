# Chapter 21: Appendix — Oracle Certifications and Course Access

The **Oracle** certification program — across Oracle Cloud Infrastructure (OCI),
Oracle Database, MySQL, and Java — organized by family, with each family's key
credentials, the year-versioned exam-code system, and the training and practice
model. The lineup was harvested on **26 July 2026** from **education.oracle.com** —
the same source that anchors
[Volume XLVII — Oracle Certification Tracks](../../volume-47-oracle-certifications/README.md).
Third-party exam-dump sites were excluded as sources.

**How access works at Oracle.** Free training is available through **Oracle
Learning Explorer** and the **OCI free tier** (Always Free), with deeper paid
courses in **Oracle University (MyLearn)**. Free **exam topics** are published on
each certification page. Hands-on practice is free on the **OCI Always Free** tier,
**Oracle Database Free** / **Autonomous Database** (free tier), **MySQL**, and
**JDK 21**. Exams are delivered through **Pearson VUE**, and credentials are managed
in **Oracle CertView**.

> **Currency.** Oracle **year-versions** many exams (the code suffix, e.g.,
> `1Z0-1072-26`) and versions others by product release (Database 23ai, Java SE
> 21) — confirm the current code on education.oracle.com before registering. Recent
> additions captured here: **OCI Generative AI Professional (1Z0-1127)**, **OCI
> Multicloud Architect**, **Oracle Database 23ai** (AI Vector Search), and **Java
> SE 21 (1Z0-830)**.

## Free training and entry points

- **[Oracle Certification](https://education.oracle.com/certification)** — the
  authoritative catalog and per-exam topics
- **Oracle Learning Explorer** — free foundational training and some free
  certifications
- **OCI Always Free tier** — free OCI resources for hands-on practice
- **Oracle Database Free / Autonomous Database (free)** and **MySQL** — free
  database practice
- **Oracle CertView** — manage and verify credentials

## Fees, delivery, and renewal

- **Fees (confirm at registration):** Foundations/associate exams are the lower
  band; professional and specialty exams are higher; some **Foundations**
  credentials are periodically **free** via Learning Explorer promotions.
- **Delivery:** **Pearson VUE** (test center or online-proctored), governed by
  published **exam topics**.
- **Prerequisites:** most OCI exams have none; professional exams assume
  experience.
- **Validity and renewal:** OCI certifications carry **recertification** timelines
  (Oracle often provides shorter delta/recert exams); Database/MySQL/Java are
  versioned by release. Confirm each credential's recertification terms in
  CertView.

## Notes

- **The exam code (year suffix / release) is the currency signal.** OCI exams roll
  the suffix annually; Database and Java version by release (23ai, Java 21).
- **Practice is free.** Use the OCI Always Free tier, Oracle Database Free/
  Autonomous, MySQL, and JDK 21 — no cost to prepare.
- **New AI credentials.** OCI **Generative AI Professional** and **Data Science
  Professional**, plus Database **23ai AI Vector Search**, are the AI-forward
  additions.
- **Multicloud is real.** OCI–Azure Interconnect and **Oracle Database@Azure/AWS/
  GCP** underpin the Multicloud Architect credential.
- **Related practice** in the encyclopedia: the cloud volumes (**XVII AWS**,
  **XXXIII Azure**, **XXXIV Google Cloud**), Kubernetes (**VIII**, **XLI**), and
  automation/IaC (**IX**, **XLII HashiCorp**).
