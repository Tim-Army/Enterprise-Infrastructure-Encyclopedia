# Chapter 52: Appendix — GitHub Certifications and Course Access

The **GitHub** certification program — the credentials for developing, automating, securing, and
administering software on GitHub — organized by certification, with the exam model, the training model,
and the delivery model. The program was verified on **29 July 2026** from **docs.github.com** and
GitHub's certification resources — the same sources that anchor
[Volume LXXXIX — GitHub Certification Tracks](../../volume-89-github-certifications/README.md).
Third-party exam-dump sites were excluded as sources.

**How access works.** GitHub's training is **free**: the interactive **GitHub Skills** courses (which run
in real repositories), the **learning paths** on GitHub's certification resources, and the docs. Each
certification page lists the **skills measured** and links to registration. Exams are booked and
delivered through **PSI** — at a test center or **online-proctored** with a secure browser — for **$99
USD** each (GitHub Foundations is currently **50% off** for a limited time), with **100 minutes** to
complete. GitHub is a Microsoft company, so the credentials are also visible on **Microsoft Learn**.
Hands-on practice uses a **free GitHub account** with local `git` and the `gh` CLI.

> **Currency.** The program has five certifications (Foundations, Actions, Advanced Security,
> Administration, and Copilot). GitHub ships features quickly — refresh skills and confirm exam
> objectives on the official certification pages as the platform evolves.

## Free and low-cost resources and entry points

- **[About GitHub Certifications](https://docs.github.com/en/get-started/showcase-your-expertise-with-github-certifications/about-github-certifications)**
  — the authoritative certifications and skills measured
- **[GitHub certification resources](https://resources.github.com/learn/certifications/)** — learning
  paths and registration
- **[GitHub Skills](https://skills.github.com/)** — **free**, interactive courses that run in real repos
- **Free GitHub account** — with local `git` and the `gh` CLI for hands-on practice
- **Registration** — via PSI from the GitHub certification pages

## Fees, delivery, and renewal

- **Fees:** **$99 USD** per exam; **GitHub Foundations 50% off** for a limited time. Training is
  **free**. Confirm current pricing on GitHub's certification pages.
- **Delivery:** **PSI** — test center or **online-proctored** (secure browser); **100 minutes**.
- **Prerequisites:** none formal; Foundations is the recommended starting point.
- **Validity and renewal:** refresh skills as GitHub ships features and exam objectives are updated.

## The certifications

Verified against docs.github.com on 29 July 2026.

| Certification | Skills measured |
| --- | --- |
| GitHub Foundations | Collaboration, GitHub products, Git basics, working within repositories |
| GitHub Actions | Streamlining workflows, automating tasks, optimizing software pipelines |
| GitHub Advanced Security | Vulnerability identification, workflow security, security implementation |
| GitHub Administration | Repository management, workflow optimization, efficient collaboration |
| GitHub Copilot | Responsible AI, Copilot plans/features/data, prompt engineering, testing, privacy/exclusions |
