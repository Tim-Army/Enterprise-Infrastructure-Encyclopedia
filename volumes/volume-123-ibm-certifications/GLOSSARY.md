# Volume CXXIII — Glossary

| Term | Definition |
|:---|:---|
| **ACE (App Connect Enterprise)** | IBM's integration engine: message flows that transform and route between systems, deployed as BAR files. |
| **AIOps (Cloud Pak for AIOps)** | IBM's ML-driven operations platform: correlates alert storms into incidents, suppresses noise, and automates remediation. |
| **BAW (Business Automation Workflow)** | IBM's workflow/BPM product: processes modeled as states, transitions, and human/system tasks. |
| **Catalog code (Cert-…)** | The IBM Training catalog identifier for a certification (e.g. Cert-C9007000); distinct from the Pearson VUE exam code (C1000-series). |
| **Cloud Pak** | An IBM software bundle packaged to run on Red Hat OpenShift (Data, Integration, Security, Business Automation, AIOps, Watson AIOps). |
| **Credly** | The digital-badge platform where IBM certifications and badges are issued and shared. |
| **DSM (Device Support Module)** | The QRadar component that parses a log source's raw events into normalized fields; wrong DSM means unparsed events. |
| **Guardium** | IBM's database activity monitoring product: captures sensitive-data access and privilege changes outside the database, so insiders cannot disable it from within. |
| **IBM i** | The integrated OS+database platform on Power, using a library/object model (not files/directories) and CL/RPG. |
| **My Learning** | IBM's portal for certification history, certificates, and records. |
| **MQ** | IBM's messaging middleware: queue managers hold queues; applications PUT/GET messages; channels connect queue managers; persistence survives restart. |
| **OnVUE** | Pearson VUE's online-proctored exam delivery, the alternative to a physical test center. |
| **Offense (QRadar)** | A prioritized security incident QRadar raises by correlating many events via rules — what analysts investigate. |
| **PLUS combination** | An IBM certification requiring both an IBM exam and a Red Hat Certified Specialist (OpenShift) exam — one credential, two vendors' exams. |
| **Planning Analytics (TM1)** | IBM's planning/forecasting engine built on multidimensional cubes, dimensions, and consolidations. |
| **QRadar SIEM** | IBM's security information and event management platform; its V7.5 certifications form an Associate→Analyst→Administrator→Deployment Professional ladder. |
| **Qiskit** | IBM's open-source quantum SDK; the Qiskit v2.X Developer certification tests building and running circuits — runnable free via `pip`. |
| **Retiring soon** | A catalog flag marking a certification being withdrawn; valid to hold, unwise to target for a new plan. |
| **TechXchange badge** | An IBM training, advocacy, or event badge — recognition of learning or contribution, **not** a proctored certification. |
| **Turbonomic** | IBM's application resource management product: continuously generates resize/move/placement actions balancing performance against cost. |
| **Verify Access** | IBM's access-management product: a reverse proxy (WebSEAL) that authenticates (with MFA/federation) and enforces authorization policy in front of applications. |
| **watsonx** | IBM's AI platform family: **watsonx.ai** (build/prompt models), **watsonx.data** (lakehouse), **watsonx.governance** (model lifecycle/risk), plus **Assistant** (conversational) and **Orchestrate** (agentic automation). |
| **WebSphere ND** | WebSphere Application Server Network Deployment: a cell managed by a deployment manager with node agents and clustered application servers. |
| **z/OS** | IBM's mainframe operating system; administration centers on JCL, JES, SMF, RACF, SDSF, and Parmlib. |
