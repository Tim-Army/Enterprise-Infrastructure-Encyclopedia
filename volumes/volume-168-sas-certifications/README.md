## Overview

**SAS** is the trusted platform for **rigorous, end-to-end analytics** — the software banks, governments, and
researchers use where results must be **correct and defensible**. Its heritage is deep **statistics**, expressed
through the **SAS language** and now the cloud-native **SAS Viya** platform (in-memory **CAS**, visual **Model
Studio** for ML, and **SAS Visual Analytics** for BI). SAS sits alongside the analytics and data platforms this
shelf covers ([Tableau CLIV](../volume-154-tableau-certifications/README.md),
[Qlik CLXI](../volume-161-qlik-certifications/README.md),
[Databricks XLVIII](../volume-048-databricks-certifications/README.md)) — its edge is validated statistics and
the SAS language behind everything.

Chapter 02 covers **the SAS platform and language** (Viya, CAS/CASL, DATA step + PROC). Chapters 03–08 take the
discipline: **programming foundations**, **preparing and curating data**, **statistical analysis**, **machine
learning on Viya**, **visual analytics and BI**, and **the Data Scientist path and Viya administration**.
Chapter 09 closes on choosing a path, with a capstone tracing the whole analytics lifecycle.

A theme runs through it: **curate** (data), **describe** (statistics), **model** (statistics + ML), **assess**
(rigorously), and **report/deploy** — the end-to-end analytics lifecycle, done with SAS's statistical rigor.

## The certifications

Three scopes across the categories:

| Scope / category | Representative credential |
| --- | --- |
| **Specialist / Programming** | Fundamentals of Programming · Programming Specialist (A00-420) · Advanced Programming |
| **Specialist / Statistics** | Statistical Business Analyst (A00-240) |
| **Specialist / AI & ML** | Machine Learning Specialist Using SAS Viya |
| **Specialist / Visual BI** | Visual Business Analytics Using SAS Viya (A00-470) |
| **Data Curation** | data preparation and management |
| **Administration** | SAS Viya Administration (A00-451) |
| **Composite** | SAS Certified Data Scientist (combine credentials) |

**Mechanics:** Pearson VUE · ~60–70 questions (some performance-based, hands-on in SAS) · passing ~high-60s–low-70s%
(Programming Specialist 71%) · ~**$180** · valid **5 years** · A00-xxx codes.

## What you will be able to do

- Read the SAS scopes (Specialist / Professional / Data Scientist) and categories, and the exam mechanics.
- Explain SAS Viya, the in-memory CAS engine, and the DATA-step/PROC language (and Viya vs SAS 9.4).
- Program in SAS — DATA-step logic and core PROCs (MEANS, FREQ, SORT, SQL).
- Curate data — merge, format, clean, validate, and handle missing values.
- Do statistics — descriptive/inferential analysis, regression, and honest model assessment.
- Build machine learning — Model Studio pipelines, model comparison, and deployment.
- Build BI — SAS Visual Analytics reports with interactions and built-in forecasting.
- Compose the Data Scientist path, or take the Viya Administration pole.

## Prerequisites

- Familiarity with data analysis and basic statistics helps; SQL knowledge eases PROC SQL.
- A Linux or macOS host with `python3`. **SAS certifications** are delivered via Pearson VUE (~$180, valid 5 years).
