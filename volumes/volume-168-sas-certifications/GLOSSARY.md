# Volume CLXVIII — Glossary

| Term | Definition |
|:---|:---|
| **CAS (Cloud Analytic Services)** | SAS Viya's distributed, in-memory compute engine — data is loaded into RAM across a cluster and analyzed there, so large-scale statistics and machine learning run fast and at scale. |
| **CASL** | The CAS language — used to script CAS actions directly against in-memory tables in SAS Viya. |
| **DATA step** | The half of the SAS language that reads, transforms, and creates data sets observation by observation — assignments, conditionals (IF/THEN), functions, loops, subsetting, and missing-value handling. |
| **Data curation** | Preparing trustworthy data — combining (concatenate / match-merge), applying formats/informats, and cleaning/validating/handling missing values; its own certification category and a pillar of the Data Scientist path. |
| **Formats / informats** | Informats tell SAS how to read an input value (a date, a currency); formats tell SAS how to display a stored value — a format changes the display, not the stored value. |
| **Model Studio** | SAS Viya's visual machine-learning environment — build supervised ML pipelines (data → transform → model → assess nodes) and compare models; the basis of the Machine Learning Specialist credential. |
| **PROC step** | A SAS procedure that does something to a data set — PROC MEANS/SUMMARY (statistics), FREQ (counts), SORT, SQL (SQL in SAS), REG/LOGISTIC (models), SGPLOT (graphs). "DATA step to prepare, PROC to analyze." |
| **SAS Certified Data Scientist** | The composite capstone credential — earned by combining several credentials (data curation, advanced programming, AI/ML, advanced analytics), certifying the whole data-science lifecycle end to end. |
| **SAS Certified Professional** | A credential level earned by passing multiple exams in a track, validating broader competency than a single-exam Specialist. |
| **SAS Certified Specialist** | The mainstream credential level — earned by passing a single exam in a focused area (e.g. Machine Learning Using SAS Viya, Visual Business Analytics). |
| **SAS language** | SAS's programming language — the DATA step (prepare data) plus PROC steps (analyze it); largely the same across SAS 9.4 and SAS Viya, so skills transfer. |
| **SAS Viya** | SAS's modern cloud-native (Kubernetes) analytics and AI platform — in-memory via CAS, with SAS Studio, Model Studio, Visual Analytics, and open APIs (call from Python/R/REST). Successor generation to SAS 9.4. |
| **SAS Visual Analytics** | SAS Viya's self-service BI tool — build interactive reports/dashboards by point-and-click, with data items (category/measure), visualizations, filters/interactions, and built-in analytics (forecasting). |
| **Statistical Business Analyst** | The advanced-analytics/statistics credential (A00-240) — applying descriptive and inferential statistics, regression/modeling, and honest assessment to business problems in SAS. |
| **Machine Learning Specialist** | The AI/ML credential (Using SAS Viya) — building supervised ML models via Model Studio pipelines: data sources, model building, assessment, and deployment. |
| **Performance-based exam** | A SAS exam format where you complete tasks hands-on in the software (not only multiple choice), validating that you can actually do the work. |
| **SAS Viya Administration** | The administration credential (A00-451) — operating SAS Viya on Kubernetes: deployment, users/groups/security, content and data governance, and monitoring. |
| **Match-merge** | Combining data sets side by side by a key (BY variable, sorted first, or PROC SQL join) — the SAS join, with care needed for sorting and non-matches. |
| **SAS 9.4** | The legacy SAS platform generation — mature, single-server/grid; runs the same SAS language as Viya, but most current certifications target "Using SAS Viya." |
