# Volume LXXIV Glossary

Definitions for terms introduced in **Volume LXXIV — GIAC (SANS) Certification Tracks**.
See the [master glossary](../../GLOSSARY.md) for cross-volume terms.

- **CyberLive** — GIAC's hands-on practical testing, where the candidate performs real tasks on live virtual machines with actual tools during the exam.
- **Focus area** — one of GIAC's eight certification categories: Essentials, Cyber Defense, Offensive Operations, DFIR, Cloud Security, ICS Security, Leadership, and Artificial Intelligence.
- **GAIPS** — GIAC AI Platform Security; auditing and securing generative-AI applications and LLM development pipelines.
- **GASAE** — GIAC AI Security Automation Engineer; applying AI and automation across offensive, defensive, and cloud operations.
- **GCCC** — GIAC Critical Controls Certification; implementing and auditing the CIS Critical Security Controls.
- **GCDA** — GIAC Certified Detection Analyst; building and tuning detections from security telemetry.
- **GCFA** — GIAC Certified Forensic Analyst; deep host and memory forensics with timelines (CyberLive).
- **GCFR** — GIAC Cloud Forensics Responder; incident response and forensics across cloud providers.
- **GCIA** — GIAC Certified Intrusion Analyst; traffic analysis and intrusion detection.
- **GCIH** — GIAC Certified Incident Handler; the incident-response lifecycle and attack techniques from the defender's view.
- **GCIP** — GIAC Critical Infrastructure Protection; compliance and controls for critical infrastructure (e.g., NERC CIP).
- **GCLD** — GIAC Cloud Security Essentials; multi-cloud fundamentals and the shared responsibility model.
- **GCSA** — GIAC Cloud Security Automation; DevSecOps, policy-as-code, and IaC scanning.
- **GCTI** — GIAC Cyber Threat Intelligence; turning observations into structured, actionable intelligence.
- **GDAT** — GIAC Defending Advanced Threats; defeating advanced adversaries via MITRE ATT&CK.
- **GDSA** — GIAC Defensible Security Architect; designing segmented, defensible architectures.
- **GEVA** — GIAC Enterprise Vulnerability Assessor; running and prioritizing vulnerability assessments.
- **GFACT** — GIAC Foundational Cybersecurity Technologies; hardware, OS, networking, programming, and data fundamentals.
- **GIAC** — Global Information Assurance Certification, the SANS Institute's technical certification body.
- **GICSP** — Global Industrial Cyber Security Professional; the flagship ICS/OT credential bridging IT, OT, and engineering.
- **GISF** — GIAC Information Security Fundamentals; entry-level security concepts, risk, and the CIA triad.
- **GMLE** — GIAC Machine Learning Engineer; applying machine learning to cybersecurity challenges.
- **GMON** — GIAC Continuous Monitoring; security operations and continuous monitoring health.
- **GNFA** — GIAC Network Forensic Analyst; reconstructing activity from network evidence.
- **GPEN** — GIAC Penetration Tester; the authorized penetration-testing process (scope, rules of engagement, methodology, reporting).
- **GREM** — GIAC Reverse-Engineering Malware; static and behavioral malware triage for indicators.
- **GRID** — GIAC Response and Industrial Defense; ICS incident response and active defense.
- **GSEC** — GIAC Security Essentials; the broad, hands-on security foundation (CyberLive).
- **GSLC** — GIAC Security Leadership; governance plus technical breadth for security leaders.
- **GSOM** — GIAC Security Operations Manager; building and running a security operations center.
- **GSTRT** — GIAC Strategic Planning, Policy, and Leadership; security strategy and policy.
- **GWEB** — GIAC Certified Web Application Defender; defending web applications by secure default.
- **Open-book exam** — GIAC's format allowing printed references and a personal index during the proctored exam.
- **Purdue model** — the reference model of ICS/OT network levels (0–5) used to segment operational technology from IT.
- **SANS Institute** — the cybersecurity training organization that owns GIAC and authors the aligned SEC/FOR/LDR/ICS courses.
