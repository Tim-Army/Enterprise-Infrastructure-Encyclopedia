Search, filter and sort the crosswalk, its prerequisites and the per-model support check; open a row for every column. Companion to Volume CLXXII. Download the data as CSV with the buttons below or from the data folder.

Source and method. Built from the workbook 11-fortiswitch-feature-version-and-srg-map-feature-map-20261103.xlsx (saved beside the CSV files in this volume's data folder) on 2026-11-04. The Crosswalk tab holds the Cisco-derived rows (those with a Cisco rule) and the FortiSwitch features migrated in from the feature list, one row per feature and SRG ID. CLI Verified by and GUI Verified by record who checked the command syntax on a switch; “Nobody” means not yet verified, and a check of the syntax does not show that a feature is supported on a model. Reference and Page point into the FortiSwitchOS 7.6.7 CLI Reference, the FortiOS 7.6.7 CLI Reference, the FortiSwitchOS 7.6.7 Administration Guide or the FortiSwitch 7.6.7 Feature Matrix. The Model support tab comes from the 7.6.7 feature matrix columns for the 6xxF series (648F-FPOE) and the 2048F. SRG versions and requirement IDs were checked against a third-party mirror of the DISA files only and still require DISA verification. Names are first names only.
