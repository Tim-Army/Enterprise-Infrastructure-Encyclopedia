WHAT A PREREQUISITE IS
Anything that must exist or be configured BEFORE a row's setting can meet its
requirement: an external server (RADIUS, TACACS+, LDAP, syslog, NTP, SNMP
manager, SFTP/SCP backup server, SIEM, identity provider), a user group or
role, a certificate or PKI enrollment, a license or subscription, a model or
hardware capability, an operating mode (for example FIPS-CC, FortiLink-
managed, HA), a managing system (FortiGate, FortiManager, EMS), a configured
interface, VLAN, or zone, an earlier setting the row depends on (for example
DHCP snooping before dynamic ARP inspection), cloud services, and so on.
Include only what the product's documentation supports; cite it.
